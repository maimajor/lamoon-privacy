更灵活地调整 Mac 屏幕

Mac 亮度已经调到最低，屏幕还是太亮？

◉

2. 打开 Lamoon

如果已发布 Lamoon.app，请按照对应版本的说明操作。常规应用可移至“应用程序”文件夹 后启动，并在菜单栏查找月亮图标。

3. 调整屏幕

先选择一个预设或使用 Film，再调节调暗滑块。如果需要白点调整且显示器支持，可尝试 Display Gamma。

两种显示调整方式

Lamoon 调整屏幕内容的显示方式，不会直接控制面板的物理背光。

◧

Film（叠加层）

在显示图像上覆盖调暗层。Gamma 调整不起作用时，这是推荐的替代方式。与其他基于叠加层的工具一样，该图层可能出现在截图或录制内容中。

◐

Display Gamma

调整显示器的 Gamma 表，并启用白点调整。某些 HDR/XDR 显示器或其他显示调整工具可能带来兼容性限制。

常见问题

Lamoon 能把 Mac 屏幕调得比 macOS 内置最低亮度更暗吗？

可以。Lamoon 提供最高 80% 的额外软件调暗控制。实际效果会因显示器和所选模式而异。

Lamoon 会改变显示器的硬件背光吗？

不会。根据所选模式，Lamoon 会使用覆盖层或调整显示器的 gamma 表来调暗画面，不会直接降低硬件背光输出。

Film（叠加层）与 Display Gamma 有什么区别？

这是两种软件显示调整方式。兼容性和显示效果可能因显示器和模式而异。白点调节（最高 80%）仅在 Display Gamma 模式下可用。

蓝光滑块会测量屏幕发出的蓝光量吗？

不会。它只是让画面色调偏暖，并不测量屏幕发出的蓝光量。滑块显示范围为 0–100%，但内部色调混合上限为 80%。

六种预设会调整什么？

它们提供便于快速上手的起始调暗值：正常 (0%)、工作 (20%)、编程 (35%)、阅读 (45%)、电影 (65%) 和睡前 (80%)。预设也可能同时应用已保存的暖色调、白点和颜色设置。

日出日落定时需要位置信息吗？

只有启用可选的日出日落定时功能时才需要位置信息。Lamoon 会通过 macOS 定位服务请求大致位置，将坐标四舍五入到小数点后两位，并保存在 Mac 本机。手动定时无需访问位置。

Night Boost 有什么作用？

启用自动夜间功能时，Night Boost 每晚最多一次将调暗值提高到 50%、暖色强度提高到 35%。它只会恢复自己提高过的数值，并且仅在你之后没有手动修改这些数值时恢复。

截图模式有什么作用？

截图模式会暂停调暗 5 秒，方便截取静态画面。它不是持续共享屏幕的模式。

Lamoon 会调暗锁屏吗？

锁屏调暗默认开启，也可以关闭。启用时，锁屏调暗最高限制为 45%。

Lamoon 会收集或传输个人数据吗？

Lamoon 会将偏好设置和日出日落定时所需的大致坐标保存在 Mac 本机。为本网站检查的源代码中没有分析、广告、遥测或崩溃报告 SDK，也没有通过网络上传数据的代码；未来版本可能有所变化。浏览网站或从 GitHub 下载项目文件仍需要互联网连接。

支持哪些 macOS 版本？是否有兼容性限制？

Lamoon 面向 macOS 13 及以上版本。Display Gamma 模式可能与 HDR 显示器或其他会改变显示输出的工具存在兼容性限制。实际效果取决于 Mac、显示器和所选模式。

如何快速重置显示设置？

使用 Control–Command–0 即可重置显示调整。自定义快捷键默认关闭，可以在设置中手动开启。

可以手动设置定时吗？

可以。你可以手动设置开始和结束时间，也可以按日出日落安排屏幕调整。手动定时不需要访问位置信息；只有启用日出日落定时后，应用才会请求大致位置。

可以暂时暂停调暗吗？

可以。暂停调暗后，屏幕会恢复正常亮度；需要再次调暗时可以继续启用。

选择“无色调”后会发生什么？

选择“无色调”后，暖色调调整会暂停，“暖色强度”滑块也会停用，但当前数值会保留。选择其他色调后，仍可继续使用之前保存的滑块数值。

如何安装 Lamoon？

打开 GitHub 项目并查看 Releases 是否发布了应用版本。如果有可下载应用，请按对应版本说明操作；常规 Lamoon.app 可以移至“应用程序”文件夹 后启动。

启动后在哪里找到 Lamoon 图标？

Lamoon 在 macOS 菜单栏运行，而不是普通的 Dock 应用。请在菜单栏控制项附近寻找月亮图标。

Lamoon 需要联网吗？

经检查的应用源代码不包含网络上传代码，主要屏幕调整在本机完成。但浏览网站或从 GitHub 下载文件仍需要网络。

Lamoon 免费吗？有 Mac App Store 版本吗？

请查看 GitHub 项目页和已发布版本说明以了解当前的可用性和价格。除非项目正式宣布，否则不要假设已有 Mac App Store 版本。

Lamoon 支持 Intel Mac 和 Apple Silicon 吗？

请查看下载版本标注的处理器架构。Universal 通用版本支持 Intel 和 Apple Silicon；需要 macOS 13 或更高版本。

为什么 Display Gamma 没有让屏幕变暗？

有些显示器对 Gamma 表更改的响应不符合预期。HDR/XDR 或其他显示调整工具也可能影响兼容性。请尝试 Film 模式。

可以同时使用 Night Shift 吗？

两者可能同时运行，但叠加后的色彩效果会有所不同。如果颜色异常，请一次调整一个工具，或将 Lamoon 切换到 Film 模式。

可以同时使用 f.lux 吗？

多个修改显示输出的工具可能互相冲突。如果使用 f.lux，请尝试 Film，或一次只运行一个显示调整工具。

Lamoon 支持外接显示器吗？

Lamoon 提供软件显示调整，但效果取决于显示器、连接方式、macOS 和所选模式。它不会直接设置显示器的物理背光。

Lamoon 支持 HDR 或 XDR 显示器吗？

Display Gamma 在 HDR/XDR 显示器上可能存在限制。如果 Gamma 调整效果不理想，请尝试 Film。

调暗效果会出现在截图或录屏中吗？

Film（叠加层）可能出现在截图或录屏中。截图模式 会暂停调暗 5 秒，以便截取静态画面；它不用于持续屏幕共享。

不提供位置权限也能设置计划吗？

可以。手动设置开始和结束时间即可。只有启用可选的日出/日落计划时才需要位置权限。

设置保存在哪里，可以删除吗？

设置保存在 macOS 应用容器的本机位置。若要删除已保存偏好设置和本地位置数据，请退出 Lamoon，再删除用户 Library 中该应用的容器文件夹；这也会移除应用设置。

自定义快捷键不起作用怎么办？

自定义快捷键默认关闭。请在设置中启用；如果与其他应用冲突，请改用另一组按键。

Lamoon 会影响 Mac 性能或电池续航吗？

资源使用和电池影响取决于所选模式、连接的显示器以及 macOS 当前的工作负载。我们尚未发布受控的电池测试，因此不能保证影响可以忽略。你可以在 Mac 的“活动监视器”中查看 Lamoon 的能耗影响。

Lamoon 会在后台运行吗？

会。Lamoon 是菜单栏工具，即使关闭控制面板，也可以继续应用显示设置。无需一直打开控制面板。

如何完全退出 Lamoon？

在 Lamoon 菜单中选择“退出”，或使用应用内的退出控件。退出时，Lamoon 会尝试恢复它修改过的显示器伽马表。如果显示效果仍异常，请重新打开 Lamoon，并使用 Control–Command–0 重置调整。

Lamoon 会随 macOS 自动启动吗？

登录时启动是可选功能，默认关闭。如需在登录时自动打开应用，请在 Lamoon 设置中启用。

Lamoon 会调暗所有已连接的显示器吗？

Lamoon 旨在调整 macOS 识别到的屏幕，包括内置和外接显示器。Film（叠加层）可以覆盖被识别的屏幕。Display Gamma 的效果因显示器而异；如果无法应用伽马调整，应用会改用叠加层作为备用方式。实际结果仍取决于硬件和 macOS 配置。

连接或断开外接显示器时会发生什么？

Lamoon 会响应 macOS 的显示器配置变化并刷新叠加层。macOS 识别显示器后，应用应会进行适配，但可能有短暂延迟。如果效果异常，请尝试 Film 或重新打开 Lamoon。

Lamoon 支持镜像显示器吗？

效果取决于 macOS 如何报告镜像布局以及所选模式。Lamoon 会处理 macOS 识别到的显示器，但不保证所有镜像配置下效果都相同。如果效果异常，请测试 Film 并检查各显示器配置。

Lamoon 能与 Sidecar（将 iPad 用作第二块屏幕）配合使用吗？

如果 macOS 将 Sidecar iPad 作为显示器提供，Film（叠加层）可以作用于 macOS 识别到的屏幕。Display Gamma 的支持情况和可见效果可能不同；并未对所有 Sidecar 配置进行独立认证。

Lamoon 支持键盘导航吗？

自定义调暗滑块具有辅助功能标签和值，可接收键盘焦点并用方向键调整。若需更全面的键盘导航，请在 macOS“系统设置”中启用“完全键盘访问”。具体操作会因控件和 macOS 版本而异。

Lamoon 对屏幕阅读器用户友好吗？

Lamoon 为自定义滑块提供辅助功能标签和可调节操作。目前尚未测试所有屏幕阅读器的全部操作流程，因此依赖特定操作前，请使用当前版本的 VoiceOver 进行测试。Film 是视觉叠加层，不提供 VoiceOver 语音朗读输出。

可以不使用鼠标操作 Lamoon 吗？

部分控件（包括自定义调暗滑块）支持键盘焦点和方向键调整。若需更全面的键盘导航，请在 macOS“系统设置”中启用“完全键盘访问”。支持范围可能因控件和 macOS 版本而异，请在已安装的版本中确认实际操作流程。

--safe 参数是什么？

运行 open -a Lamoon --args --safe 可在安全模式下启动 Lamoon。应用会使用安全的默认显示设置，而不是已保存的偏好设置，以帮助排查由设置或显示调整引起的问题。这不是通用的数据删除工具。

屏幕共享时可以使用 Lamoon 吗？

根据捕获方式不同，Film（叠加层）可能出现在截图、录制或某些屏幕共享画面中。截图模式 只会为静态截图暂停调暗 5 秒，并非持续屏幕共享模式。会议前请先测试；如果显示器支持，也可以试试 Display Gamma。

Lamoon 能与 Stage Manager 一起使用吗？

Lamoon 可以与 Stage Manager 同时运行，但 Film 使用叠加窗口，在 macOS 窗口或 Spaces 切换时行为可能不同。Display Gamma 会调整显示器的传递表，但部分显示器可能不支持。请在 Mac 上测试两种模式；与 Stage Manager 的兼容性并不保证适用于所有配置。

Lamoon 与 macOS 深色模式有什么区别？

macOS 深色模式会改变受支持界面和应用的外观。Lamoon 专注于软件调暗和色调控制，包括最高 80% 调暗、六种色调，以及 Display Gamma 模式中的白点调整。实际效果取决于显示器和模式。

Lamoon 需要账户或会显示广告吗？

此处介绍的 Lamoon 版本无需账户或登录。为本网站检查的源代码中没有广告或分析 SDK；未来版本可能有所变化。

关于 Lamoon

Lamoon 是一款 macOS 菜单栏应用，适合希望更细致地控制屏幕调暗和色调的用户，尤其是在昏暗环境、夜间或专注工作时。

软件调暗不会控制显示器的硬件背光。显示效果会因 Mac、显示器、macOS 版本和所选模式而异。Display Gamma 模式可能与 HDR 或其他显示调节工具存在兼容性限制。Lamoon 不作医疗功效宣称。应用内的帮助标记和提示气泡会在使用过程中说明各项控件的用途。
