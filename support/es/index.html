Soporte y solución de problemas de Lamoon

Pasos prácticos para problemas habituales de pantalla y configuración. Los resultados varían según el Mac, la pantalla, la conexión, macOS y el modo elegido.

Preguntas frecuentes

Display Gamma no oscurece la pantalla

Algunas pantallas ignoran o limitan los cambios de la tabla gamma, especialmente con HDR/XDR u otras herramientas. Cambia a Film y vuelve a probar.

El control del punto blanco está desactivado

El punto blanco solo está disponible en Display Gamma. Cambia de modo si la pantalla es compatible; Film puede atenuar y teñir, pero no ofrece ese control independiente.

He denegado el acceso a la ubicación

La ubicación es opcional y solo se usa para programar amanecer/atardecer. Define horas manuales. Para revisar el permiso, abre Ajustes del Sistema → Privacidad y seguridad → Localización.

La superposición aparece en una captura

La superposición Film puede salir en las capturas. Usa modo de captura para pausar la atenuación cinco segundos antes de tomar una imagen fija; no sirve para compartir pantalla continuamente.

¿Cómo restauro rápidamente la pantalla?

Usa Control–Comando–0 para restablecer los ajustes de pantalla. Si sigue viéndose mal, vuelve a abrir Lamoon y prueba Film.

El control de calidez está desactivado

El tono True (sin tinte) pausa el tono cálido y desactiva el control, pero conserva su valor. Selecciona Warm, Amber, Deep, Red o Green para aplicar un tinte.

La pantalla de bloqueo se ve diferente

La atenuación de la pantalla de bloqueo es opcional, está activada por defecto y tiene un límite del 45 %. Puedes desactivarla en los ajustes de Lamoon.

¿Lamoon puede cambiar la retroiluminación física?

No. Lamoon cambia el contenido mostrado mediante una superposición o la tabla gamma; no ajusta directamente la retroiluminación física del panel.

La programación solar no restauró mis valores

La función nocturna solo restaura los valores que aumentó y solo si no los cambiaste después. Comprueba las horas manuales y la programación solar.

Los atajos personalizados no responden

Activa los atajos personalizados en los ajustes. Si otra app utiliza la misma combinación, asigna otra.

Los ajustes no se conservan al volver a abrir Lamoon

Activa Remember settings en los ajustes generales si quieres conservar los valores entre sesiones.

¿Necesitas más ayuda?

Lee el README del proyecto y abre una incidencia en GitHub con la versión de macOS, el tipo de pantalla, el modo elegido y los pasos para reproducir el problema. No incluyas datos privados de ubicación.

El monitor externo no se oscurece en Display Gamma

Algunos monitores externos pueden no responder a los cambios de la tabla gamma, especialmente en ciertas configuraciones HDR/XDR. Prueba el modo Film, diseñado para funcionar con las pantallas que macOS detecta. El tipo de conexión por sí solo no garantiza que Display Gamma sea compatible. Si el problema continúa, anota el modelo de Mac, la versión de macOS, el modelo de monitor, la conexión y el modo elegido.

Contacto y recursos del proyecto

Para informar de un problema reproducible, incluye la versión de macOS, el tipo de pantalla, el modo elegido y los pasos para reproducirlo. No compartas datos privados de ubicación.
