LAMOON · ช่วยเหลือ

Lamoon: ศูนย์ช่วยเหลือและแก้ปัญหา

แนวทางแก้ปัญหาที่พบบ่อยเกี่ยวกับจอและการตั้งค่า Lamoon ผลลัพธ์อาจแตกต่างตาม Mac จอ การเชื่อมต่อ macOS และโหมดที่เลือก

คำถามที่พบบ่อย

Display Gamma ไม่ทำให้จอมืดลง

จอบางรุ่นอาจไม่รองรับหรือจำกัดการเปลี่ยน Gamma โดยเฉพาะการใช้ร่วมกับ HDR/XDR หรือเครื่องมืออื่น ให้เปลี่ยนไปใช้ Film แล้วทดสอบอีกครั้ง

ตัวเลื่อน White Point ปิดใช้งาน

White Point ใช้ได้เฉพาะ Display Gamma ให้เปลี่ยนโหมดหากจอรองรับ โหมด Film หรี่และปรับโทนสีได้ แต่ไม่มีตัวควบคุม White Point แยกต่างหาก

ปฏิเสธสิทธิ์เข้าถึงตำแหน่งไปแล้ว

ตำแหน่งเป็นตัวเลือกและใช้เฉพาะตารางเวลาพระอาทิตย์ขึ้น–ตก ให้กำหนดเวลาเริ่มและสิ้นสุดเอง หากต้องการตรวจสิทธิ์ ให้เปิด System Settings → Privacy & Security → Location Services

เลเยอร์หรี่จอติดไปในภาพหน้าจอ

โหมด Film ใช้เลเยอร์ทับภาพที่อาจปรากฏในการจับภาพ ใช้ Capture Mode เพื่อหยุดการหรี่ 5 วินาทีก่อนถ่ายภาพนิ่ง ไม่ได้รองรับการแชร์หน้าจอต่อเนื่อง

คืนค่าหน้าจออย่างรวดเร็วได้อย่างไร?

ใช้ Control–Command–0 เพื่อรีเซ็ตการปรับจอ หากภาพยังผิดปกติ ให้เปิด Lamoon อีกครั้งและลองโหมด Film

ตัวเลื่อนโทนอุ่นใช้งานไม่ได้

โทน True (ไม่ย้อมสี) จะหยุดการย้อมโทนอุ่นและปิดตัวเลื่อน แต่ยังจำค่าที่ตั้งไว้ เลือก Warm, Amber, Deep, Red หรือ Green เพื่อใช้การย้อมสี

หน้าจอล็อกมีลักษณะแตกต่าง

การหรี่หน้าจอล็อกเป็นการตั้งค่าแยก เปิดไว้โดยค่าเริ่มต้น และจำกัดการหรี่ไม่เกิน 45% สามารถปิดได้ในการตั้งค่า Lamoon

Lamoon ปรับไฟแบ็กไลต์จริงของจอได้ไหม?

ไม่ได้ Lamoon เปลี่ยนภาพที่แสดงด้วยเลเยอร์ทับภาพหรือการปรับ Gamma ไม่ได้ตั้งค่าไฟแบ็กไลต์จริงของแผงจอโดยตรง

Solar Scheduling ไม่คืนค่าการตั้งค่า

ตารางเวลากลางคืนจะคืนเฉพาะค่าที่ระบบเพิ่มขึ้น และเฉพาะกรณีที่คุณไม่ได้แก้ค่าเหล่านั้นหลังจากนั้น ตรวจสอบเวลาเริ่ม/สิ้นสุดและการตั้งค่า Solar Scheduling

คีย์ลัดที่กำหนดเองไม่ตอบสนอง

เปิดใช้คีย์ลัดในการตั้งค่า หากแอปอื่นใช้ชุดคีย์เดียวกัน ให้กำหนดชุดใหม่

การตั้งค่าหายเมื่อเปิด Lamoon ใหม่

เปิด Remember settings ใน General settings หากต้องการให้ค่าคงอยู่ระหว่างการใช้งานแต่ละครั้ง

ยังต้องการความช่วยเหลือ

อ่าน README ของโปรเจกต์และเปิด issue บน GitHub พร้อมแจ้งเวอร์ชัน macOS ประเภทจอ โหมดที่เลือก และขั้นตอนที่ทำให้เกิดปัญหา อย่าแนบข้อมูลตำแหน่งส่วนตัว

จอภายนอกไม่มืดลงในโหมด Display Gamma

จอภายนอกบางรุ่นอาจไม่ตอบสนองต่อการเปลี่ยน gamma table โดยเฉพาะบางการตั้งค่าที่ใช้ HDR/XDR ให้ลองเปลี่ยนเป็น Film ซึ่งออกแบบมาให้ทำงานกับจอที่ macOS ตรวจพบ ประเภทสายเชื่อมต่อเพียงอย่างเดียวไม่รับประกันว่า Display Gamma จะรองรับ หากยังมีปัญหา โปรดบันทึกรุ่น Mac เวอร์ชัน macOS รุ่นจอ วิธีเชื่อมต่อ และโหมดที่เลือก

ติดต่อและข้อมูลโปรเจกต์

หากแจ้งปัญหา ให้ระบุเวอร์ชัน macOS ประเภทหรือรุ่นจอ โหมดที่เลือก และขั้นตอนที่ทำให้เกิดปัญหา อย่าเปิดเผยข้อมูลตำแหน่งส่วนตัว
