Lamoon Support & Troubleshooting

Practical steps for common Lamoon display and settings issues. Results can vary by Mac, display, connection, macOS version, and selected mode.

Frequently asked questions

Display Gamma does not make the screen darker

Some displays ignore or limit gamma-table changes, especially in certain HDR/XDR or multi-tool setups. Switch to Film mode and test again.

The White Point slider is disabled

White Point is available only in Display Gamma mode. Switch modes if compatible; Film mode can dim and tint but does not offer the separate White Point control.

I denied location access

Location is optional and is used only for sunrise/sunset scheduling. Set manual start and end times instead. To review access, open System Settings → Privacy & Security → Location Services.

The dimming layer appears in a screenshot

Film mode uses an overlay that may appear in captures. Use Capture Mode to pause dimming for five seconds before taking a still screenshot; it is not continuous screen-sharing support.

How do I quickly restore the display?

Use Control–Command–0 to reset display adjustments. If the result still looks wrong, reopen Lamoon and try Film mode.

The warmth slider is disabled

The True (untinted) tone pauses warmth tinting and disables that slider while preserving its saved value. Select Warm, Amber, Deep, Red, or Green to use tinting.

The lock screen looks different

Lock-screen dimming is a separate optional setting, enabled by default and capped at 45%. You can turn it off in Lamoon settings.

Can Lamoon change the display’s physical backlight?

No. Lamoon changes displayed content using an overlay or gamma-table adjustments; it does not directly set the panel’s physical backlight.

Solar Scheduling did not restore my settings

Night scheduling restores only values it raised, and only if you have not changed those values since. Check manual times and solar-scheduling settings.

Custom hotkeys do not respond

Enable custom hotkeys in settings. If another app uses the same shortcut, assign a different key combination.

Settings reset when I relaunch Lamoon

Turn on Remember settings in General settings if you want values to persist between sessions.

Still need help?

Review the project README and open an issue on GitHub with your macOS version, display type, selected mode, and steps to reproduce. Do not include private location information.

External monitor does not dim in Display Gamma mode

Some external displays do not respond to gamma-table changes, especially in certain HDR/XDR or system configurations. Try Film mode, which uses an overlay on displays macOS detects. HDMI, USB-C and Thunderbolt connections do not by themselves guarantee gamma-table support. If the problem remains, include your Mac model, macOS version, monitor model, connection type and selected mode when contacting support.

Contact and project resources

For reproducible issues, include your macOS version, display model or type, selected mode, and steps to reproduce. Do not share private location data.
