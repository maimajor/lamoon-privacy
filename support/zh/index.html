Lamoon 支持与故障排查

以下是常见显示和设置问题的处理步骤。实际效果可能因 Mac、显示器、连接方式、macOS 和所选模式而异。

常见问题

Display Gamma 无法调暗屏幕

部分显示器会忽略或限制 Gamma 表更改，尤其在 HDR/XDR 或与其他工具同时使用时。请切换到 Film 后重试。

白点滑块不可用

白点仅在 Display Gamma 模式下可用。如果显示器支持，请切换模式。Film 可以调暗和调整色调，但不提供独立的白点控制。

我拒绝了位置权限

位置权限是可选的，仅用于日出/日落计划。请改为手动设置开始和结束时间。可在系统设置 → 隐私与安全性 → 定位服务中检查权限。

截图中出现叠加层

Film（叠加层）可能出现在截图中。截取静态画面前可使用 截图模式 暂停调暗 5 秒；该模式不支持持续屏幕共享。

如何快速恢复正常显示？

使用 Control–Command–0 重置显示调整。如果显示仍然异常，请重新打开 Lamoon 并尝试 Film。

暖色滑块不可用

True（无色调）会暂停暖色调并禁用滑块，但保留当前数值。选择 Warm、Amber、Deep、Red 或 Green 可启用色调效果。

锁定屏幕的显示不同

锁屏调暗是单独的可选设置，默认开启，调暗上限为 45%。可在 Lamoon 设置中关闭。

Lamoon 能改变物理背光吗？

不能。Lamoon 通过叠加层或 Gamma 表改变显示内容，不会直接设置面板的物理背光。

日落计划没有恢复我的设置

夜间计划只会恢复其提高过的数值，并且仅在你之后没有手动更改这些数值时才恢复。请检查手动时间和日照计划设置。

自定义快捷键没有响应

请在设置中启用自定义快捷键。如果其他应用占用了相同组合，请分配不同的按键组合。

重新启动 Lamoon 后设置丢失

如果希望不同会话之间保留数值，请在常规设置中启用 Remember settings。

仍需要帮助

查看项目 README，并在 GitHub 提交 issue，附上 macOS 版本、显示器类型、所选模式和复现步骤。请勿包含私人位置数据。

外接显示器在 Display Gamma 模式下没有变暗

某些外接显示器可能不会响应伽马表更改，尤其是在部分 HDR/XDR 配置下。请尝试 Film 模式，它旨在适用于 macOS 识别的屏幕。仅凭连接类型无法保证支持 Display Gamma。如果问题仍然存在，请记录 Mac 型号、macOS 版本、显示器型号、连接方式和所选模式。

联系与项目资源

报告可复现的问题时，请注明 macOS 版本、显示器类型、所选模式和复现步骤。请勿分享私人位置数据。
