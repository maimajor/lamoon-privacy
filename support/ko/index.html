Lamoon 지원 및 문제 해결

디스플레이와 설정에서 자주 발생하는 문제에 대한 안내입니다. 결과는 Mac, 디스플레이, 연결, macOS, 선택한 모드에 따라 다릅니다.

자주 묻는 질문

Display Gamma로 화면이 어두워지지 않음

일부 디스플레이는 감마 테이블 변경을 무시하거나 제한합니다. 특히 HDR/XDR 또는 다른 도구를 함께 사용할 때 그렇습니다. Film으로 전환해 다시 시도하세요.

화이트 포인트 슬라이더가 비활성화됨

화이트 포인트는 Display Gamma 모드에서만 사용할 수 있습니다. 디스플레이가 지원하면 모드를 전환하세요. Film은 디밍과 색조 조정은 가능하지만 별도 화이트 포인트 제어는 없습니다.

위치 접근을 거부함

위치 권한은 선택 사항이며 일출·일몰 예약에만 사용됩니다. 시작과 종료 시간을 직접 설정하세요. 권한은 시스템 설정 → 개인정보 보호 및 보안 → 위치 서비스에서 확인할 수 있습니다.

스크린샷에 오버레이가 나타남

Film(오버레이)는 캡처에 나타날 수 있습니다. 정지 화면을 찍기 전에 캡처 모드로 5초 동안 디밍을 일시 중지하세요. 지속적인 화면 공유용은 아닙니다.

화면을 빠르게 초기화하려면?

Control–Command–0을 사용해 디스플레이 조정을 초기화하세요. 화면이 여전히 이상하면 Lamoon을 다시 열고 Film을 사용해 보세요.

따뜻함 슬라이더가 비활성화됨

True(색조 없음)는 따뜻한 색조를 일시 중지하고 슬라이더를 비활성화하지만 저장된 값은 유지합니다. 색조를 사용하려면 Warm, Amber, Deep, Red, Green을 선택하세요.

잠금 화면이 다르게 보임

잠금 화면 디밍은 별도 선택 설정으로 기본 활성화되어 있고 최대 45%로 제한됩니다. Lamoon 설정에서 끌 수 있습니다.

물리적 백라이트를 바꿀 수 있나요?

아니요. Lamoon은 오버레이 또는 감마 테이블을 통해 표시되는 콘텐츠를 바꾸며 패널 백라이트를 직접 설정하지 않습니다.

Solar Scheduling이 설정을 복원하지 않음

야간 예약은 자동으로 높인 값만 복원하며 이후 사용자가 해당 값을 변경하지 않은 경우에만 복원합니다. 수동 시간과 Solar Scheduling 설정을 확인하세요.

사용자 지정 단축키가 반응하지 않음

설정에서 사용자 지정 단축키를 켜세요. 다른 앱과 충돌하면 다른 조합을 지정하세요.

Lamoon을 다시 실행하면 설정이 사라짐

세션 사이에 값을 유지하려면 일반 설정에서 Remember settings를 켜세요.

추가 도움이 필요함

프로젝트 README를 확인하고 macOS 버전, 디스플레이 종류, 선택 모드, 재현 단계를 포함해 GitHub 이슈를 등록하세요. 개인 위치 정보는 포함하지 마세요.

Display Gamma 모드에서 외장 모니터가 어두워지지 않음

일부 외장 디스플레이는 감마 테이블 변경에 반응하지 않을 수 있으며, 특정 HDR/XDR 구성에서 이런 문제가 발생할 수 있습니다. macOS가 인식하는 화면에서 작동하도록 설계된 Film 모드를 사용해 보세요. 연결 방식만으로 Display Gamma 지원을 보장할 수 없습니다. 문제가 계속되면 Mac 모델, macOS 버전, 모니터 모델, 연결 방식, 선택한 모드를 기록하세요.

문의 및 프로젝트 자료

재현 가능한 문제를 신고할 때 macOS 버전, 디스플레이 종류, 선택한 모드, 재현 단계를 적으세요. 개인 위치 정보는 공유하지 마세요.
