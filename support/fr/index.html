Assistance et dépannage Lamoon

Étapes pratiques pour les problèmes courants d’écran et de réglages. Les résultats varient selon le Mac, l’écran, la connexion, macOS et le mode choisi.

← AccueilConfidentialité

Questions fréquentes

Display Gamma n’assombrit pas l’écran

Certains écrans ignorent ou limitent les changements de table gamma, notamment avec HDR/XDR ou d’autres outils. Passez à Film et réessayez.

Le curseur Point blanc est désactivé

Le point blanc est disponible uniquement en mode Display Gamma. Changez de mode si l’écran le prend en charge ; Film peut assombrir et teinter mais ne propose pas ce réglage séparé.

J’ai refusé l’accès à la localisation

La localisation est facultative et sert uniquement aux horaires de lever/coucher du soleil. Définissez des heures manuelles. Pour vérifier l’autorisation, ouvrez Réglages Système → Confidentialité et sécurité → Service de localisation.

La superposition apparaît dans une capture

La superposition Film peut apparaître dans les captures. Utilisez mode capture pour mettre l’assombrissement en pause pendant cinq secondes avant une image fixe ; ce n’est pas une solution de partage d’écran continu.

Comment rétablir rapidement l’affichage ?

Utilisez Contrôle–Commande–0 pour réinitialiser les réglages de l’écran. Si l’affichage reste anormal, rouvrez Lamoon et essayez Film.

Le curseur de chaleur est désactivé

Le ton True (sans teinte) suspend la teinte chaude et désactive le curseur tout en conservant sa valeur. Choisissez Warm, Amber, Deep, Red ou Green pour appliquer une teinte.

L’écran verrouillé paraît différent

L’assombrissement de l’écran verrouillé est facultatif, activé par défaut et plafonné à 45 %. Vous pouvez le désactiver dans les réglages de Lamoon.

Lamoon peut-il changer le rétroéclairage physique ?

Non. Lamoon modifie le contenu affiché avec une superposition ou la table gamma ; il ne règle pas directement le rétroéclairage physique du panneau.

La programmation solaire n’a pas restauré mes valeurs

La programmation nocturne ne restaure que les valeurs qu’elle a augmentées, et seulement si vous ne les avez pas modifiées depuis. Vérifiez les horaires manuels et le réglage solaire.

Les raccourcis personnalisés ne répondent pas

Activez les raccourcis personnalisés dans les réglages. Si une autre app utilise la même combinaison, choisissez-en une autre.

Les réglages ne persistent pas au redémarrage

Activez Remember settings dans les réglages généraux pour conserver les valeurs entre les sessions.

Besoin d’aide supplémentaire ?

Consultez le README du projet et ouvrez une issue sur GitHub en indiquant la version de macOS, le type d’écran, le mode choisi et les étapes de reproduction. N’incluez pas de données de localisation privées.

Le moniteur externe ne s’assombrit pas en mode Display Gamma

Certains écrans externes peuvent ne pas réagir aux changements de table gamma, notamment dans certaines configurations HDR/XDR. Essayez le mode Film, conçu pour fonctionner avec les écrans détectés par macOS. Le type de connexion ne garantit pas à lui seul la prise en charge de Display Gamma. Si le problème persiste, notez le modèle du Mac, la version de macOS, le moniteur, la connexion et le mode choisi.

Contact et ressources du projet

Pour signaler un problème reproductible, indiquez la version de macOS, le type d’écran, le mode choisi et les étapes pour le reproduire. Ne partagez pas de données de localisation privées.
