Mac 화면을 더 세밀하게 조절

Mac 밝기를 최저로 낮춰도 화면이 여전히 너무 밝나요?

macOS 밝기를 최저로 낮췄는데도 화면이 너무 밝다면 Lamoon에서 소프트웨어 방식으로 화면을 더 어둡게 하고 색조를 조절할 수 있습니다. 모든 기능을 메뉴 막대 패널 하나에 모았습니다. 디스플레이의 실제 백라이트 밝기를 직접 제어하지는 않습니다.

기능

기본 밝기 조절만으로 부족하다고 느끼는 Mac 사용자를 위해 Lamoon은 소프트웨어 어둡게 조절, 색상 조정, 일정 설정을 한곳에 제공합니다.

화면을 더 어둡게

◉

따뜻한 색조

화면 색을 더 따뜻하게 조절합니다. 방출되는 블루라이트 양을 측정하는 기능은 아닙니다.

◐

화이트 포인트

화이트 포인트는 최대 80%까지 조절할 수 있으며 Display Gamma 모드에서만 사용할 수 있습니다.

✦

색상 톤

색상 없음, 따뜻함, 앰버, 진한 색, 레드, 그린 중에서 선택할 수 있습니다.

▦

여섯 가지 프리셋

일반 (0%), 작업 (20%), 코딩 (35%), 읽기 (45%), 영화 (65%), 취침 (80%) 중에서 선택합니다.

◷

일출·일몰 일정

시작 및 종료 시간을 직접 설정하거나 현지 일출·일몰에 맞춰 예약할 수 있습니다. 대략적인 위치 정보는 일출·일몰 일정 기능을 켠 경우에만 Mac에 저장됩니다.

◧

⌕

디스플레이 진단

Mac 내장 화면과 외장 모니터를 함께 어둡게 합니다. Film(오버레이)은 모든 디스플레이에서 사용할 수 있으며 Display Gamma는 각 디스플레이의 지원 여부에 따라 달라집니다.

◷

Ⅱ

디밍 일시 정지 및 재개

Mac 화면을 최소 밝기보다 더 어둡게 하는 방법

세 단계로 Lamoon을 시작하세요. 다운로드할 수 있는 빌드가 공개되어 있는지는 GitHub에서 확인해야 합니다.

↓

1. 릴리스 확인

GitHub의 Lamoon 프로젝트를 열고 Releases에서 다운로드 가능한 빌드와 설치 안내가 있는지 확인합니다.

◉

2. Lamoon 실행

Lamoon.app이 공개되어 있다면 해당 릴리스 안내를 따르세요. 일반 앱 번들은 Applications 폴더로 옮겨 실행하고 메뉴 막대에서 달 아이콘을 찾습니다.

☼

3. 화면 조정

프리셋으로 시작하거나 Film을 선택한 뒤 디밍 슬라이더를 조절합니다. 화이트 포인트가 필요하고 디스플레이가 지원하면 Display Gamma를 사용해 보세요.

두 가지 디스플레이 조정 방식

Lamoon은 화면에 표시되는 콘텐츠를 조정하며 패널의 물리적 백라이트를 직접 제어하지 않습니다.

◧

Film(오버레이)

표시된 이미지 위에 디밍 레이어를 겹칩니다. 감마 조정이 효과가 없을 때 권장되는 대안입니다. 다른 오버레이 기반 도구와 마찬가지로 이 레이어는 스크린샷이나 녹화에 나타날 수 있습니다.

◐

Display Gamma

디스플레이 감마 테이블을 조정하고 화이트 포인트를 활성화합니다. HDR/XDR 디스플레이나 다른 화면 조정 도구는 호환성에 제한을 줄 수 있습니다.

Lamoon은 누구에게 적합할까요?

의학적 또는 눈 건강 효과를 약속하지 않고 디스플레이와 사용 습관에 맞게 화면을 조정하세요.

☾

늦은 밤 작업

어두운 방에서 화면을 더 어둡게 설정하세요.

⌘

코딩과 글쓰기

코딩 또는 작업 프리셋으로 시작해 디밍과 색조를 조절하세요.

▤

독서

읽기 프리셋을 사용하고 원하는 따뜻함으로 조절하세요.

▶

영화 감상

더 강한 디밍과 중립 색조를 위해 영화 프리셋으로 시작하세요.

◐

취침 전

높은 디밍과 앰버 색조의 취침 프리셋을 사용해 보세요.

▣

외장 디스플레이

Mac 내장 디스플레이와 외장 모니터를 포함해 연결된 모든 디스플레이를 동시에 어둡게 합니다. Film(오버레이)은 모든 디스플레이에서 사용할 수 있으며, Display Gamma는 감마 테이블 지원 여부와 연결 방식에 따라 결과가 달라집니다.

▣

프레젠테이션

어두운 공간에서 내 화면을 어둡게 조정하세요. Film(오버레이)가 공유 화면이나 녹화에 나타날 수 있으므로 발표 전에 공유·캡처 결과를 확인하세요.

◈

사진 편집

색 정확도가 중요한 작업에서는 중립 톤을 사용하고 추가 오버레이나 디스플레이 조정을 거친 화면만으로 최종 색상을 판단하지 마세요. Lamoon은 디스플레이 보정 도구가 아닙니다.

▶

영상 편집

작업 환경에 맞게 밝기를 조정하되 색상 관련 판단은 일반적인 보정된 검토 절차로 확인하세요. Film(오버레이)는 캡처에 나타날 수 있습니다.

Lamoon 시작을 위한 팁

Lamoon을 실용적으로 사용하는 방법입니다. 의료 조언이 아니며 화면 결과는 디스플레이마다 다를 수 있습니다.

01

프리셋부터 시작하기

작업, 코딩, 읽기, 영화 또는 취침 전을 선택한 다음 화면과 공간에 맞게 슬라이더를 미세 조정하세요.

02

먼저 Film 사용하기

Film은 오버레이를 사용합니다. 화이트 포인트가 필요하고 디스플레이가 감마 테이블 변경을 제대로 지원하면 Display Gamma로 전환하세요.

03

저녁 시간 예약하기

위치 정보 없이 시작·종료 시간을 직접 설정하거나 일출·일몰에 맞추는 일출·일몰 일정을 켜세요.

04

Night Boost 이해하기

자동 야간 모드가 켜져 있으면 Night Boost가 밤마다 한 번 어둡게 하기를 50%, 따뜻함을 35%까지 높일 수 있습니다. 이후 사용자가 값을 변경하지 않았다면 Night Boost가 올린 값만 복원합니다.

05

정지 화면에는 캡처 모드 사용하기

정지 스크린샷을 찍기 전에 5초 동안 어둡게 하기를 일시 중지하세요. 전체 녹화나 회의 동안 계속 중지하도록 설계된 기능은 아닙니다.

사용 상황별 권장 시작값

처음 네 행은 앱 프리셋 값을 반영합니다. 낮 시간 행은 수동 시작값의 예이며 저장된 프리셋이 아닙니다.

디스플레이 호환성 한눈에 보기

Film과 Display Gamma는 서로 다른 방식으로 동작합니다. 이 표는 예상 동작과 일반적인 제한을 설명하며 모든 디스플레이 모델을 인증하는 것은 아닙니다. 연결 방식만으로 Display Gamma 지원을 보장할 수 없습니다.

Lamoon 용어집: 디스플레이 주요 용어

이 페이지에서 언급하는 디스플레이 제어 및 설정에 대한 간단한 설명입니다.

소프트웨어 디밍

패널의 물리적 백라이트를 직접 제어하는 대신 오버레이나 감마 테이블 조정으로 화면 콘텐츠의 체감 밝기를 낮춥니다.

Film(오버레이)

화면 이미지 위에 놓이는 반투명 레이어입니다. Lamoon의 오버레이 방식이며 스크린샷이나 녹화에 나타날 수 있습니다.

Display Gamma

디스플레이 감마/전달 테이블을 조정하며 화이트 포인트 기능을 사용할 수 있게 합니다. 지원 여부는 디스플레이에 따라 다릅니다.

화이트 포인트

전체 디밍과 별도로 밝은 흰색 영역의 강도를 낮춥니다. Display Gamma 모드에서만 사용할 수 있습니다.

따뜻한 색조 / 블루라이트 슬라이더

화면 색상을 더 따뜻한 톤으로 조정합니다. 화면에서 방출되는 블루라이트의 양을 측정하지 않으며 차단되는 양을 검증하지도 않습니다.

색상 톤

색상 없음, 웜, 앰버, 진한 색, 레드, 그린 중 선택하는 색상 필터입니다.

프리셋

디밍, 따뜻함, 화이트 포인트, 색상 톤을 조합해 저장한 설정입니다.

일출·일몰 일정

현지 일출과 일몰에 맞추는 선택 기능입니다. 기능을 켠 경우에만 macOS 위치 서비스를 통해 대략적인 위치를 요청하며, 좌표는 소수점 이하 두 자리로 반올림해 Mac에 로컬로 저장합니다.

Night Boost

자동 야간 모드가 활성화되면 Night Boost가 밤마다 한 번 디밍을 50%, 따뜻함을 35%까지 높일 수 있습니다. Night Boost가 높인 값만 복원하며, 이후 사용자가 값을 변경하지 않은 경우에만 복원합니다.

캡처 모드

정지 화면 캡처를 위해 디밍을 5초 동안 일시 중지합니다.

핫 플러그

앱 실행 중 외장 모니터 연결 또는 분리와 같은 디스플레이 변경을 감지합니다.

자주 묻는 질문

Lamoon은 macOS 기본 최저 밝기보다 화면을 더 어둡게 할 수 있나요?

네. Lamoon은 최대 80%의 소프트웨어 추가 어둡게 조절을 제공합니다. 실제 결과는 디스플레이와 선택한 모드에 따라 달라집니다.

디스플레이의 실제 백라이트 밝기를 바꾸나요?

아니요. 선택한 모드에 따라 오버레이를 사용하거나 디스플레이 감마 테이블을 조정합니다. 물리적인 백라이트 출력을 직접 낮추지는 않습니다.

Film(오버레이) 모드와 Display Gamma 모드는 어떻게 다른가요?

두 가지 소프트웨어 표시 방식입니다. 호환성과 화면 느낌은 디스플레이와 모드에 따라 다를 수 있습니다. 화이트 포인트(최대 80%)는 Display Gamma 모드에서만 사용할 수 있습니다.

블루라이트 슬라이더는 화면에서 방출되는 블루라이트의 양을 측정하나요?

아니요. 화면 색조를 더 따뜻하게 조절하는 기능이며 방출량을 측정하지 않습니다. 슬라이더는 0–100%로 표시되지만 내부 색조 혼합은 최대 80%로 제한됩니다.

6가지 프리셋은 무엇을 바꾸나요?

화면을 어둡게 하는 정도의 시작값을 빠르게 선택합니다: 일반 (0%), 작업 (20%), 코딩 (35%), 읽기 (45%), 영화 (65%), 취침 (80%). 저장된 따뜻한 색조, 화이트 포인트와 색상 톤도 함께 적용될 수 있습니다.

일출·일몰 일정에 위치 정보가 필요한가요?

위치 정보는 일출·일몰 일정 기능을 켠 경우에만 필요합니다. Lamoon은 macOS 위치 서비스를 통해 대략적인 위치를 요청하고 좌표를 소수점 이하 두 자리로 반올림해 Mac에 로컬로 저장합니다. 수동 일정에는 위치 정보가 필요하지 않습니다.

Night Boost는 무엇을 하나요?

자동 야간 기능이 활성화되어 있으면 Night Boost가 밤마다 한 번 디밍 값을 50%로, 따뜻한 색조 값을 35%로 높일 수 있습니다. Boost가 변경한 값만 복원하며, 이후 사용자가 직접 바꾸지 않은 경우에만 복원합니다.

캡처 모드는 무엇인가요?

정지 화면을 캡처할 수 있도록 화면 어둡게 조절을 5초 동안 일시 중지합니다. 지속적인 화면 공유용 모드는 아닙니다.

잠금 화면도 어두워지나요?

잠금 화면 어둡게 하기는 기본으로 켜져 있으며 끌 수 있습니다. 기능이 작동할 때 잠금 화면의 어둡게 조절은 최대 45%로 제한됩니다.

Lamoon은 개인 데이터를 수집하거나 전송하나요?

Lamoon은 설정과 일출·일몰 일정에 사용하는 대략적인 좌표를 Mac에 로컬로 저장합니다. 이 사이트를 위해 확인한 소스 코드에는 분석·광고·텔레메트리·충돌 보고 SDK나 네트워크로 데이터를 업로드하는 코드가 없습니다. 향후 버전에서는 달라질 수 있습니다. 프로젝트 파일을 확인하거나 다운로드하려면 웹사이트와 GitHub에 인터넷으로 접속해야 합니다.

어떤 macOS 버전을 지원하며 호환성 제한이 있나요?

macOS 13 이상을 대상으로 합니다. Display Gamma 모드는 HDR 디스플레이나 화면 출력을 변경하는 다른 도구와 호환성 제한이 있을 수 있습니다. 결과는 Mac, 디스플레이와 모드에 따라 달라집니다.

화면 설정을 빠르게 초기화하려면 어떻게 하나요?

Control–Command–0을 사용합니다. 사용자 지정 단축키는 기본적으로 꺼져 있으며 설정에서 켤 수 있습니다.

시간을 직접 설정할 수 있나요?

네. 시작 및 종료 시간을 직접 설정하거나 일출·일몰에 맞춰 예약할 수 있습니다. 수동 일정에는 위치 정보 접근이 필요하지 않습니다. 대략적인 위치는 일출·일몰 일정 기능을 켠 경우에만 요청됩니다.

화면 어둡게 하기를 잠시 중지할 수 있나요?

네. 화면 어둡게 하기를 일시 중지하면 일반 화면 밝기로 돌아가며, 다시 어둡게 하고 싶을 때 재개할 수 있습니다.

색상 톤에서 ‘색상 없음’을 선택하면 어떻게 되나요?

색조를 ‘없음’으로 선택하면 따뜻한 색조 적용이 일시 중지되고 따뜻함 슬라이더가 비활성화되지만 현재 값은 유지됩니다. 다른 색조를 선택하면 저장된 슬라이더 값을 다시 사용할 수 있습니다.

Lamoon은 어떻게 설치하나요?

GitHub 프로젝트를 열고 Releases에 공개된 빌드가 있는지 확인하세요. 앱 다운로드가 가능하면 해당 릴리스 안내를 따르세요. 일반적인 Lamoon.app은 Applications 폴더로 옮겨 실행할 수 있습니다.

실행 후 Lamoon 아이콘은 어디에 있나요?

Lamoon은 일반 Dock 앱이 아니라 macOS 메뉴 막대에서 실행됩니다. 메뉴 막대 컨트롤 근처에서 달 아이콘을 찾으세요.

Lamoon을 사용하려면 인터넷이 필요한가요?

검토한 앱 소스에는 네트워크 업로드 코드가 없으며 핵심 디스플레이 조정은 로컬에서 작동합니다. 웹사이트 탐색이나 GitHub 다운로드에는 인터넷이 필요합니다.

Lamoon은 무료인가요? Mac App Store에도 있나요?

현재 제공 여부와 가격은 GitHub와 공개 릴리스 노트에서 확인하세요. 프로젝트가 발표하기 전까지 Mac App Store 버전이 있다고 가정하지 마세요.

Intel Mac과 Apple Silicon을 지원하나요?

다운로드한 빌드에 표시된 아키텍처를 확인하세요. Universal 빌드는 Intel과 Apple Silicon을 모두 지원하며 macOS 13 이상이 필요합니다.

Display Gamma로 화면이 어두워지지 않는 이유는 무엇인가요?

일부 디스플레이는 감마 테이블 변경에 예상대로 반응하지 않습니다. HDR/XDR 또는 다른 디스플레이 도구가 호환성에 영향을 줄 수 있으므로 Film 모드를 시도하세요.

Night Shift와 함께 사용할 수 있나요?

함께 실행할 수 있지만 색상 결과는 달라질 수 있습니다. 색상이 예상과 다르면 한 번에 하나의 도구만 조정하거나 Lamoon을 Film 모드로 바꿔 보세요.

f.lux와 함께 사용할 수 있나요?

화면 출력을 바꾸는 여러 도구가 충돌할 수 있습니다. f.lux를 사용한다면 Film을 시험하거나 화면 조정 도구를 한 번에 하나씩 사용해 보세요.

외부 모니터에서도 작동하나요?

Lamoon은 소프트웨어 디스플레이 조정을 제공하지만 결과는 모니터, 연결 방식, macOS, 선택 모드에 따라 다릅니다. 모니터의 물리적 백라이트를 직접 설정하지는 않습니다.

HDR 또는 XDR 디스플레이에서도 작동하나요?

HDR/XDR 디스플레이에서는 Display Gamma에 제한이 있을 수 있습니다. 감마 조정이 예상대로 작동하지 않으면 Film을 사용해 보세요.

스크린샷이나 녹화에 디밍이 나타나나요?

Film(오버레이)는 스크린샷이나 녹화에 나타날 수 있습니다. 캡처 모드는 정지 화면 캡처를 위해 5초 동안 디밍을 일시 중지하며 지속적인 화면 공유용은 아닙니다.

위치 정보를 제공하지 않고 예약할 수 있나요?

가능합니다. 시작 및 종료 시간을 직접 설정하세요. 위치 접근은 선택적 일출·일몰 예약에만 필요합니다.

설정은 어디에 저장되며 삭제할 수 있나요?

설정은 macOS 앱 컨테이너에 로컬 저장됩니다. 저장된 환경설정과 로컬 위치 데이터를 삭제하려면 Lamoon을 종료하고 사용자 Library에서 앱 컨테이너 폴더를 제거하세요. 앱 설정도 함께 삭제됩니다.

사용자 지정 단축키가 작동하지 않으면 어떻게 하나요?

사용자 지정 단축키는 기본적으로 꺼져 있습니다. 설정에서 켜고 다른 앱과 충돌하면 다른 키 조합을 지정하세요.

Lamoon이 Mac 성능이나 배터리에 영향을 주나요?

리소스 사용량과 배터리 영향은 선택한 모드, 연결된 디스플레이, macOS의 작업 상태에 따라 달라질 수 있습니다. 정식 배터리 벤치마크를 공개하지 않았으므로 영향이 거의 없다고 보장할 수 없습니다. Mac의 활성 상태 보기에서 Lamoon의 에너지 영향을 확인할 수 있습니다.

Lamoon은 백그라운드에서 실행되나요?

네. Lamoon은 메뉴 막대 유틸리티로, 제어 패널을 닫아도 디스플레이 설정을 계속 적용할 수 있습니다. 패널을 열어 둔 상태일 필요는 없습니다.

Lamoon을 완전히 종료하려면 어떻게 하나요?

Lamoon 메뉴에서 종료를 선택하거나 앱의 종료 컨트롤을 사용하세요. 종료할 때 Lamoon은 변경한 디스플레이 감마 테이블을 복원하려고 합니다. 화면이 여전히 이상하면 Lamoon을 다시 열고 Control–Command–0으로 조정을 초기화하세요.

Lamoon은 macOS와 함께 자동으로 시작하나요?

로그인 시 자동 실행은 선택 기능이며 기본적으로 꺼져 있습니다. 로그인할 때 앱을 시작하려면 Lamoon 설정에서 켜세요.

Lamoon은 연결된 모든 디스플레이를 어둡게 하나요?

Lamoon은 내장 및 외장 디스플레이를 포함해 macOS가 인식하는 화면을 조정하도록 설계되었습니다. Film(오버레이)는 감지된 화면을 덮을 수 있습니다. Display Gamma는 디스플레이마다 다르며 감마 조정을 적용할 수 없으면 앱이 오버레이를 대안으로 사용합니다. 결과는 하드웨어와 macOS 구성에 따라 달라집니다.

외장 디스플레이를 연결하거나 분리하면 어떻게 되나요?

Lamoon은 macOS의 디스플레이 구성 변경에 반응해 오버레이를 갱신합니다. macOS가 모니터를 인식하면 조정되지만 약간 지연될 수 있습니다. 결과가 이상하면 Film을 사용하거나 Lamoon을 다시 여세요.

미러링된 디스플레이에서도 작동하나요?

macOS가 미러링 구성을 보고하는 방식과 선택한 모드에 따라 달라집니다. Lamoon은 macOS가 인식하는 디스플레이를 처리하지만 모든 미러링 구성에서 같은 결과를 보장하지는 않습니다. 예상과 다르면 Film을 시험하고 각 디스플레이 구성을 확인하세요.

Sidecar(iPad를 보조 디스플레이로 사용)에서 작동하나요?

macOS가 Sidecar iPad를 디스플레이로 노출하면 Film(오버레이)가 macOS가 인식하는 화면에 적용될 수 있습니다. Display Gamma 지원 및 실제 결과는 달라질 수 있으며 모든 Sidecar 구성이 개별 검증된 것은 아닙니다.

키보드 탐색을 지원하나요?

사용자 지정 디밍 슬라이더에는 접근성 레이블과 값이 있으며 키보드 포커스와 화살표 키 조정을 지원합니다. 더 폭넓은 키보드 탐색을 위해 macOS 시스템 설정에서 전체 키보드 접근을 켜세요. 정확한 탐색 방식은 컨트롤과 macOS 버전에 따라 다를 수 있습니다.

스크린 리더 사용자도 이용할 수 있나요?

Lamoon의 사용자 지정 슬라이더는 접근성 레이블과 조정 동작을 제공합니다. 모든 스크린 리더에서 모든 작업 흐름을 테스트한 것은 아니므로 특정 작업에 의존하기 전에 현재 빌드에서 VoiceOver로 테스트하세요. Film은 시각적 오버레이이며 VoiceOver 음성 출력을 제공하지 않습니다.

마우스 없이 Lamoon을 사용할 수 있나요?

사용자 지정 디밍 슬라이더를 포함한 일부 컨트롤은 키보드 포커스와 화살표 키 조정을 지원합니다. 더 폭넓게 탐색하려면 macOS 시스템 설정에서 전체 키보드 접근을 켜세요. 지원 범위는 컨트롤과 macOS 버전에 따라 다르므로 설치한 버전에서 실제 동작을 확인하세요.

--safe 플래그는 무엇인가요?

open -a Lamoon --args --safe 명령으로 Lamoon을 안전 모드로 실행하세요. 저장된 설정 대신 안전한 기본 디스플레이 설정을 사용하므로 저장된 설정이나 화면 조정으로 생긴 문제를 진단하는 데 도움이 됩니다. 일반적인 데이터 삭제 도구는 아닙니다.

화면 공유 중 Lamoon을 사용할 수 있나요?

Film(오버레이)는 캡처 방식에 따라 스크린샷, 녹화 또는 일부 화면 공유에 나타날 수 있습니다. 캡처 모드는 정지 화면을 위해 5초 동안 디밍을 중지하며 지속적인 화면 공유 모드는 아닙니다. 회의 전에 테스트하거나 디스플레이가 지원하면 Display Gamma를 사용해 보세요.

Stage Manager와 함께 작동하나요?

Lamoon은 Stage Manager와 함께 실행할 수 있지만 Film은 오버레이 창을 사용하므로 macOS 창이나 Spaces를 전환할 때 동작이 달라질 수 있습니다. Display Gamma는 디스플레이 전달 테이블을 조정하지만 일부 디스플레이는 지원하지 않을 수 있습니다. Mac에서 두 모드를 테스트해 보세요. 모든 환경에서 Stage Manager 호환성이 보장되는 것은 아닙니다.

Lamoon은 macOS 다크 모드와 어떻게 다른가요?

macOS 다크 모드는 지원되는 인터페이스와 앱의 외관을 바꿉니다. Lamoon은 최대 80% 디밍, 6가지 색상 톤, Display Gamma 모드의 화이트 포인트 등 소프트웨어 디밍과 색상 제어에 집중합니다. 결과는 디스플레이와 모드에 따라 다릅니다.

Lamoon은 계정이 필요하거나 광고를 표시하나요?

여기에서 설명하는 Lamoon 버전은 계정이나 로그인이 필요하지 않습니다. 이 사이트를 위해 확인한 소스 코드에는 광고 또는 분석 SDK가 포함되어 있지 않습니다. 향후 버전에서는 달라질 수 있습니다.

Lamoon 소개

Lamoon은 어두운 공간이나 저녁, 집중해서 작업할 때 Mac 화면의 디밍과 색조를 세밀하게 조절하려는 사용자를 위한 macOS 메뉴 막대 앱입니다.

소프트웨어 방식의 화면 어둡게 조절은 실제 백라이트를 제어하지 않습니다. 결과는 Mac, 디스플레이, macOS 버전과 선택한 모드에 따라 다릅니다. Display Gamma 모드는 HDR 또는 다른 디스플레이 도구와 호환성 제한이 있을 수 있습니다. 의료 효과를 주장하지 않습니다. 앱의 도움말 표시와 툴팁에서 각 조절 항목의 사용 방법을 확인할 수 있습니다.

설치 안내와 문제 해결은 지원 페이지에서 확인하세요.
