ควบคุมการแสดงผล Mac ได้มากขึ้น

ปรับความสว่าง Mac ลงต่ำสุดแล้ว แต่หน้าจอยังสว่างเกินไปหรือไม่?

หากปรับความสว่าง macOS ต่ำสุดแล้วจอยังสว่างเกินไป Lamoon เพิ่มการหรี่ด้วยซอฟต์แวร์ พร้อมเครื่องมือปรับโทนการแสดงผลในแผงเดียวบนแถบเมนู แอปไม่ได้ควบคุมไฟแบ็กไลต์ของจอโดยตรง

คุณสมบัติ

สำหรับผู้ใช้ Mac ที่ต้องการควบคุมหน้าจอมากกว่าตัวเลื่อนความสว่างของระบบ Lamoon รวมการหรี่จอด้วยซอฟต์แวร์ การปรับสี และการตั้งเวลาไว้ในที่เดียว

◉

◷

◧

หรี่แถบเมนู

เลือกหรี่แถบเมนูของ macOS ได้ด้วย เพื่อให้ภาพรวมของเดสก์ท็อปมืดลง

วิธีปรับภาพหน้าจอสองแบบ

Lamoon ปรับวิธีแสดงผลของภาพ ไม่ได้ควบคุมไฟแบ็กไลต์จริงของแผงจอโดยตรง

◧

Film (เลเยอร์ทับภาพ)

วางเลเยอร์หรี่แสงทับภาพที่แสดง เป็นทางเลือกสำรองที่แนะนำเมื่อการปรับ Gamma ไม่มีผล เช่นเดียวกับเครื่องมือที่ใช้เลเยอร์ทับภาพอื่น ๆ เลเยอร์นี้อาจปรากฏในภาพหน้าจอหรือวิดีโอที่บันทึก

◐

Display Gamma

ปรับตาราง Gamma ของจอและเปิดใช้ White Point จอ HDR/XDR บางรุ่นหรือแอปปรับภาพอื่นอาจจำกัดความเข้ากันได้

เคล็ดลับเริ่มต้นใช้งาน Lamoon

แนวทางใช้งานที่นำไปลองได้ ไม่ใช่คำแนะนำทางการแพทย์ และผลลัพธ์อาจต่างกันไปตามจอแต่ละรุ่น

01

เริ่มจากพรีเซ็ต

เลือก Work, Coding, Reading, Movie หรือ Bedtime แล้วปรับแถบเลื่อนให้เหมาะกับจอและห้องของคุณ

02

ลอง Film ก่อน

Film ใช้เลเยอร์ทับภาพ ลองเปลี่ยนเป็น Display Gamma เมื่อต้องการใช้ White Point และจอรองรับการปรับ gamma table ได้ถูกต้อง

03

ตั้งเวลาช่วงเย็น

กำหนดเวลาเริ่มและสิ้นสุดเองโดยไม่ต้องใช้ตำแหน่งที่ตั้ง หรือเปิด Solar Scheduling ให้ทำงานตามพระอาทิตย์ขึ้นและตกในพื้นที่

04

ทำความเข้าใจ Night Boost

เมื่อโหมดกลางคืนอัตโนมัติทำงาน Night Boost สามารถเพิ่มการหรี่จอเป็น 50% และความอุ่นเป็น 35% ได้คืนละหนึ่งครั้ง จากนั้นจะคืนค่าเฉพาะค่าที่ฟีเจอร์นี้เพิ่มไว้ หากคุณไม่ได้เปลี่ยนค่าเหล่านั้นภายหลัง

05

ใช้ Capture Mode กับภาพนิ่ง

พักการหรี่จอเป็นเวลา 5 วินาทีก่อนถ่ายภาพหน้าจอแบบนิ่ง ฟีเจอร์นี้ไม่ได้ออกแบบมาเพื่อพักการหรี่จอตลอดการบันทึกหรือประชุม

ความเข้ากันได้กับจอโดยสรุป

Film และ Display Gamma ทำงานต่างกัน ตารางนี้อธิบายพฤติกรรมที่ตั้งใจไว้และข้อจำกัดที่พบบ่อย ไม่ใช่การรับรองจอทุกรุ่น ประเภทสายเชื่อมต่อเพียงอย่างเดียวไม่สามารถรับประกันว่า Display Gamma จะรองรับ

จอภายนอกผ่าน USB-C / Thunderboltออกแบบมาให้ครอบคลุมจอที่ macOS ตรวจพบขึ้นอยู่กับการรองรับ gamma table ของจอความเข้ากันได้แตกต่างกันตามรุ่นจอและการตั้งค่า macOS

โปรเจกเตอร์รองรับจอที่ macOS เปิดให้แอปเข้าถึงขึ้นอยู่กับโปรเจกเตอร์และเส้นทางสัญญาณควรทดสอบก่อนเริ่มนำเสนอ
จอแบบ Mirroringขึ้นอยู่กับรูปแบบจอที่ macOS ตรวจพบขึ้นอยู่กับแต่ละจอและการตั้งค่า Mirroringหากผลลัพธ์ไม่เป็นไปตามคาด ให้ลอง Film

หากจอภายนอกไม่มืดลงตามที่คาด ให้ลอง Film ก่อน หากต้องการแจ้งปัญหา โปรดระบุรุ่น Mac, เวอร์ชัน macOS, รุ่นจอ, วิธีเชื่อมต่อ และโหมดที่เลือก

อภิธานศัพท์ Lamoon: คำศัพท์เกี่ยวกับจอ

คำอธิบายสั้น ๆ ของตัวควบคุมและการตั้งค่าที่กล่าวถึงในหน้านี้

การหรี่จอด้วยซอฟต์แวร์

ลดความสว่างที่มองเห็นของภาพด้วยเลเยอร์ทับภาพหรือการปรับ gamma table แทนการควบคุม Backlight จริงของแผงจอโดยตรง

Film (เลเยอร์ทับภาพ)

เลเยอร์โปร่งแสงที่วางทับภาพบนจอ เป็นวิธีหรี่จอแบบ overlay ของ Lamoon และอาจปรากฏในภาพหน้าจอหรือวิดีโอที่บันทึก

Display Gamma

ปรับ gamma หรือ transfer table ของจอเพื่อทำให้ภาพมืดลง และเป็นโหมดที่เปิดให้ใช้ White Point ความเข้ากันได้ขึ้นอยู่กับจอ

ตัวเลือกตั้งเวลาอัตโนมัติตามเวลาพระอาทิตย์ขึ้นและตกในพื้นที่ ระบบขอตำแหน่งโดยประมาณผ่าน macOS Location Services เฉพาะเมื่อเปิดใช้ พิกัดจะปัดเศษเป็นทศนิยม 2 ตำแหน่งและเก็บไว้ในเครื่อง

Night Boost

เมื่อโหมดกลางคืนอัตโนมัติทำงาน Night Boost สามารถเพิ่มการหรี่จอเป็น 50% และความอุ่นเป็น 35% ได้คืนละหนึ่งครั้ง ระบบจะคืนค่าเฉพาะค่าที่เพิ่มขึ้น และเฉพาะเมื่อคุณไม่ได้เปลี่ยนค่าเหล่านั้นภายหลัง

คำถามที่พบบ่อย

Lamoon หรี่จอให้มืดกว่าค่าต่ำสุดของ macOS ได้ไหม?

ได้ Lamoon เพิ่มการหรี่ด้วยซอฟต์แวร์ โดยตัวเลื่อนได้สูงสุด 80% ผลที่เห็นขึ้นอยู่กับจอและโหมดที่เลือก

Lamoon เปลี่ยนความสว่างของไฟแบ็กไลต์จริงหรือไม่?

ไม่ Lamoon ใช้หน้าต่างโอเวอร์เลย์หรือปรับตาราง Gamma ของจอตามโหมดที่เลือก ไม่ได้ลดความสว่างของไฟแบ็กไลต์จริงโดยตรง

Film (เลเยอร์ทับภาพ) กับ Display Gamma ต่างกันอย่างไร?

เป็นวิธีปรับการแสดงผลด้วยซอฟต์แวร์ 2 แบบ ความเข้ากันได้และลักษณะภาพอาจต่างกันตามจอและโหมด White Point (สูงสุด 80%) ใช้ได้เฉพาะ Display Gamma

ตัวเลื่อนลดแสงสีฟ้าวัดปริมาณแสงสีฟ้าที่หน้าจอปล่อยออกมาหรือไม่?

ไม่ ตัวเลื่อนปรับสีของภาพให้มีโทนอุ่นขึ้น แต่ไม่ได้วัดปริมาณแสงสีฟ้าที่หน้าจอปล่อยออกมา แม้ตัวเลื่อนจะแสดง 0–100% แต่การผสมโทนสีภายในจำกัดสูงสุด 80%

พรีเซ็ต 6 แบบตั้งค่าอะไรบ้าง?

เป็นค่าตั้งต้นสำหรับความมืด ได้แก่ ปกติ (0%), ทำงาน (20%), เขียนโค้ด (35%), อ่านหนังสือ (45%), ดูหนัง (65%) และก่อนนอน (80%) และอาจใช้ค่าโทนอุ่น White Point และโทนสีที่บันทึกไว้ร่วมด้วย

Solar Scheduling ต้องใช้ตำแหน่งหรือไม่?

ต้องใช้ตำแหน่งโดยประมาณเฉพาะเมื่อเปิดการตั้งเวลาตามพระอาทิตย์ขึ้น–ตก Lamoon ขอข้อมูลผ่าน macOS Location Services ปัดเศษพิกัดเป็นทศนิยม 2 ตำแหน่ง และเก็บไว้ในเครื่อง หากไม่อนุญาตตำแหน่ง ยังตั้งเวลาเริ่มและสิ้นสุดเองได้

Night Boost ทำอะไร?

เมื่อเปิดระบบกลางคืนอัตโนมัติ Night Boost สามารถปรับความมืดเป็น 50% และค่าความอุ่นเป็น 35% ได้หนึ่งครั้งต่อคืน โดยคืนค่าเฉพาะค่าที่Night Boost เปลี่ยน และเฉพาะเมื่อผู้ใช้ยังไม่ได้เปลี่ยนค่านั้นภายหลัง

Capture Mode ทำอะไร?

Capture Mode พักการหรี่จอ 5 วินาทีเพื่อให้จับภาพนิ่งได้ เป็นการพักชั่วคราว ไม่ใช่โหมดแชร์หน้าจอต่อเนื่อง

Lamoon หรี่หน้าจอล็อกด้วยหรือไม่?

การหรี่หน้าจอล็อกเปิดไว้โดยปริยายและปิดได้ เมื่อทำงานจะจำกัดการหรี่ไว้สูงสุด 45%

Lamoon เก็บหรือส่งข้อมูลส่วนบุคคลหรือไม่?

Lamoon เก็บค่าตั้งค่าและพิกัดโดยประมาณสำหรับการตั้งเวลาตามพระอาทิตย์ขึ้น–ตกไว้ในเครื่อง ซอร์สโค้ดที่ตรวจสำหรับเว็บไซต์นี้ไม่มี SDK วิเคราะห์ข้อมูล โฆษณา telemetry หรือรายงานแครช และไม่มีโค้ดอัปโหลดข้อมูลผ่านเครือข่าย เวอร์ชันในอนาคตอาจเปลี่ยนแปลงได้ เว็บไซต์และ GitHub ต้องใช้อินเทอร์เน็ตเพื่อดูหรือดาวน์โหลดไฟล์โปรเจกต์

รองรับ macOS เวอร์ชันใด และมีข้อจำกัดอะไร?

Lamoon กำหนดเป้าหมาย macOS 13 ขึ้นไป โหมด Display Gamma อาจมีข้อจำกัดกับจอ HDR หรือเครื่องมืออื่นที่ปรับการแสดงผล ผลลัพธ์แตกต่างกันตาม Mac จอ และโหมด

รีเซ็ตการปรับหน้าจออย่างรวดเร็วได้อย่างไร?

ใช้ Control–Command–0 เพื่อรีเซ็ตการปรับหน้าจอได้ทันที โดยไม่ต้องเปิดใช้คีย์ลัดแบบกำหนดเอง ส่วนคีย์ลัดอื่น ๆ ปิดไว้เป็นค่าเริ่มต้นและเปิดใช้ได้ในการตั้งค่า

ตั้งเวลาเองได้หรือไม่?

ได้ คุณกำหนดเวลาเริ่มและสิ้นสุดเอง หรือเลือกตั้งเวลาตามพระอาทิตย์ขึ้นและตกก็ได้ การตั้งเวลาเองไม่ต้องใช้ตำแหน่งที่ตั้ง ระบบจะขอตำแหน่งโดยประมาณเฉพาะเมื่อเปิดใช้การตั้งเวลาตามพระอาทิตย์

พักการหรี่จอชั่วคราวได้ไหม?

ได้ คุณพักการหรี่จอเพื่อกลับไปใช้ความสว่างปกติ แล้วเปิดการหรี่ต่อเมื่ออยากใช้ความมืดเพิ่มเติมอีกครั้ง

เมื่อเลือกโทนสี “สีจริง” จะเกิดอะไรขึ้น?

เมื่อเลือกโทนสี “สีจริง” ระบบจะหยุดการปรับโทนอุ่นและปิดตัวเลื่อนความอุ่นชั่วคราว แต่ยังคงจำค่าปัจจุบันไว้ เมื่อเลือกโทนสีอื่นจึงกลับมาใช้ค่าที่บันทึกไว้ได้

ติดตั้ง Lamoon อย่างไร?

เปิดโปรเจกต์บน GitHub แล้วตรวจหน้า Releases ว่ามีไฟล์แอปเผยแพร่หรือไม่ หากมีให้ทำตามคำแนะนำของรุ่นนั้น แอป Lamoon.app แบบทั่วไปสามารถย้ายไป Applications แล้วเปิดได้

เปิดแอปแล้วไอคอน Lamoon อยู่ที่ไหน?

Lamoon ทำงานจากแถบเมนู macOS ไม่ใช่แอป Dock ทั่วไป ให้มองหาไอคอนรูปดวงจันทร์ใกล้ส่วนควบคุมบนแถบเมนู

Lamoon ต้องใช้อินเทอร์เน็ตหรือไม่?

ซอร์สแอปที่ตรวจสอบไม่มีโค้ดอัปโหลดผ่านเครือข่าย และการปรับจอหลักทำงานในเครื่อง แต่การเปิดเว็บหรือดาวน์โหลดไฟล์จาก GitHub ยังต้องใช้อินเทอร์เน็ต

Lamoon ฟรีหรือมีบน Mac App Store หรือไม่?

ตรวจหน้า GitHub และบันทึกการเผยแพร่ล่าสุดเพื่อดูสถานะและราคา อย่าสมมติว่ามีบน Mac App Store จนกว่าโปรเจกต์จะประกาศ

Lamoon รองรับ Mac Intel และ Apple Silicon หรือไม่?

ตรวจสถาปัตยกรรมที่ระบุไว้ในไฟล์ที่ดาวน์โหลด Universal build รองรับทั้ง Intel และ Apple Silicon และต้องใช้ macOS 13 ขึ้นไป

ทำไม Display Gamma ถึงไม่ทำให้จอมืดลง?

จอบางรุ่นอาจไม่ตอบสนองต่อการเปลี่ยน Gamma ตามคาด โดยเฉพาะจอ HDR/XDR หรือเมื่อมีเครื่องมือปรับภาพอื่น ลองเปลี่ยนไปใช้ Film

ใช้ Lamoon พร้อม Night Shift ได้ไหม?

อาจใช้ร่วมกันได้ แต่สีที่ได้เมื่อเปิดทั้งสองอย่างอาจแตกต่างกัน หากสีผิดไปจากที่ต้องการ ให้ปรับทีละเครื่องมือหรือเปลี่ยน Lamoon เป็น Film

ใช้ Lamoon พร้อม f.lux ได้ไหม?

เครื่องมือหลายตัวที่ปรับการแสดงผลอาจขัดกัน หากใช้ f.lux ให้ลอง Film หรือทดสอบเปิดเครื่องมือปรับจอทีละตัว

Lamoon ใช้กับจอภายนอกได้ไหม?

Lamoon ปรับการแสดงผลด้วยซอฟต์แวร์ แต่ผลลัพธ์ขึ้นอยู่กับจอ การเชื่อมต่อ macOS และโหมดที่เลือก แอปไม่ได้ตั้งค่าไฟแบ็กไลต์จริงของจอโดยตรง

Lamoon ใช้กับจอ HDR หรือ XDR ได้ไหม?

โหมด Display Gamma อาจมีข้อจำกัดกับจอ HDR/XDR ลองใช้ Film หากการปรับ Gamma ไม่ได้ผลตามคาด

การหรี่จอปรากฏในภาพหน้าจอหรือวิดีโอไหม?

เลเยอร์ Film อาจติดไปกับภาพหน้าจอหรือวิดีโอ Capture Mode หยุดการหรี่ 5 วินาทีสำหรับการจับภาพนิ่ง ไม่ได้ออกแบบมาสำหรับแชร์หน้าจอต่อเนื่อง

ตั้งเวลาหรี่จอโดยไม่แชร์ตำแหน่งได้ไหม?

ได้ เลือกกำหนดเวลาเริ่มและสิ้นสุดเอง การเข้าถึงตำแหน่งใช้เฉพาะเมื่อเปิดตารางเวลาพระอาทิตย์ขึ้น–ตก

การตั้งค่าเก็บไว้ที่ไหน และลบได้ไหม?

การตั้งค่าเก็บไว้ใน app container ของ macOS ในเครื่อง หากต้องการลบค่าที่บันทึกและข้อมูลตำแหน่งในเครื่อง ให้ปิด Lamoon แล้วลบโฟลเดอร์ container ของแอปจาก Library ของผู้ใช้ การทำเช่นนี้จะลบการตั้งค่าที่บันทึกด้วย

หากคีย์ลัดไม่ทำงานควรทำอย่างไร?

คีย์ลัดกำหนดเองปิดไว้เป็นค่าเริ่มต้น ให้เปิดใช้งานในการตั้งค่า หากแอปอื่นใช้คีย์ชุดเดียวกัน ให้เปลี่ยนเป็นชุดอื่น

Lamoon มีผลต่อประสิทธิภาพ Mac หรือแบตเตอรี่หรือไม่?

การใช้ทรัพยากรและผลต่อแบตเตอรี่อาจขึ้นอยู่กับโหมดที่เลือก จอที่เชื่อมต่อ และงานที่ macOS กำลังทำอยู่ เรายังไม่ได้เผยแพร่ผลทดสอบแบตเตอรี่แบบควบคุม จึงไม่สามารถรับรองว่าผลกระทบน้อยมากได้ คุณสามารถตรวจค่า Energy Impact ของ Lamoon ใน Activity Monitor บน Mac ของคุณ

Lamoon ทำงานอยู่เบื้องหลังหรือไม่?

ใช่ Lamoon เป็นยูทิลิตีบนแถบเมนู และสามารถคงการตั้งค่าจอไว้ได้แม้ปิดแผงควบคุม ไม่จำเป็นต้องเปิดแผงค้างไว้เพื่อให้เอฟเฟกต์การหรี่จอทำงานต่อ

จะปิด Lamoon อย่างสมบูรณ์ได้อย่างไร?

เลือก Quit จากเมนู Lamoon หรือใช้ปุ่ม Quit ของแอป เมื่อแอปปิดลง Lamoon จะพยายามคืนค่า gamma table ของจอที่แก้ไขไว้ หากภาพยังผิดปกติ ให้เปิด Lamoon อีกครั้งแล้วใช้ Control–Command–0 เพื่อรีเซ็ต

Lamoon เปิดพร้อม macOS โดยอัตโนมัติหรือไม่?

การเปิด Lamoon เมื่อเข้าสู่ระบบเป็นตัวเลือกเสริมและปิดไว้เป็นค่าเริ่มต้น หากต้องการให้แอปเปิดเองเมื่อลงชื่อเข้าใช้ ให้เปิดใช้ใน Settings ของ Lamoon

Lamoon หรี่จอที่เชื่อมต่อทั้งหมดหรือไม่?

Lamoon ออกแบบมาเพื่อปรับจอที่ macOS ตรวจพบ รวมถึงจอในตัวและจอภายนอก Film (เลเยอร์ทับภาพ) สามารถครอบคลุมจอที่ macOS ตรวจพบ ส่วน Display Gamma อาจแตกต่างกันตามจอ หากใช้ gamma ไม่ได้ แอปจะใช้ overlay เป็นทางเลือก ผลลัพธ์ยังขึ้นอยู่กับฮาร์ดแวร์และการตั้งค่า macOS

จะเกิดอะไรขึ้นเมื่อเชื่อมต่อหรือถอดจอภายนอก?

Lamoon ตอบสนองต่อการเปลี่ยนการจัดวางจอของ macOS และปรับ overlay ใหม่ โดยปกติจะปรับตามหลังระบบรู้จักจอ แต่อาจมีความล่าช้าสั้น ๆ หากภาพไม่ถูกต้อง ให้ลอง Film หรือเปิด Lamoon ใหม่

Lamoon ใช้กับจอแบบ Mirroring ได้หรือไม่?

พฤติกรรมขึ้นอยู่กับวิธีที่ macOS รายงานการทำ Mirroring และโหมดที่เลือก Lamoon จัดการจอที่ macOS ตรวจพบ แต่ไม่รับประกันผลเหมือนกันทุกการตั้งค่า หากผลลัพธ์ไม่เป็นไปตามคาด ให้ทดสอบ Film และตรวจการตั้งค่าจอแต่ละจอ

Lamoon ใช้กับ Sidecar (ใช้ iPad เป็นจอที่สอง) ได้หรือไม่?

หาก macOS แสดง iPad ที่ใช้ Sidecar เป็นจอ Film (เลเยอร์ทับภาพ) ของ Lamoon ก็สามารถทำงานกับจอที่ macOS ตรวจพบได้ การรองรับ Display Gamma และผลที่เห็นอาจแตกต่างกัน ยังไม่รับประกันการทำงานกับ Sidecar ในทุกการตั้งค่า

Lamoon รองรับการนำทางด้วยคีย์บอร์ดหรือไม่?

แถบเลื่อนหรี่จอแบบกำหนดเองมีป้ายกำกับและค่าการช่วยการเข้าถึง รับโฟกัสด้วยคีย์บอร์ดและปรับด้วยปุ่มลูกศรได้ สำหรับการนำทางด้วยคีย์บอร์ดที่ครอบคลุมขึ้น ให้เปิด Full Keyboard Access ในการตั้งค่าระบบ macOS การนำทางอาจแตกต่างกันตามตัวควบคุมและเวอร์ชัน macOS

Lamoon รองรับผู้ใช้โปรแกรมอ่านหน้าจอหรือไม่?

แถบเลื่อนแบบกำหนดเองของ Lamoon มีป้ายกำกับและการปรับค่าที่ช่วยการเข้าถึง แต่ยังไม่ได้ทดสอบทุกขั้นตอนกับโปรแกรมอ่านหน้าจอทุกตัว จึงควรทดสอบกับ VoiceOver ในเวอร์ชันที่ใช้อยู่ก่อนพึ่งพาการทำงานเฉพาะอย่าง Film เป็นเอฟเฟกต์ภาพและไม่มีเสียงอ่านจาก VoiceOver

ใช้ Lamoon โดยไม่ใช้เมาส์ได้หรือไม่?

ตัวควบคุมบางส่วน รวมถึงแถบเลื่อนหรี่จอแบบกำหนดเอง รองรับการโฟกัสด้วยคีย์บอร์ดและการปรับด้วยปุ่มลูกศร เปิด Full Keyboard Access ในการตั้งค่าระบบ macOS เพื่อเพิ่มการนำทาง ทั้งนี้ความครอบคลุมอาจต่างกันตามตัวควบคุมและเวอร์ชัน macOS จึงควรตรวจสอบการใช้งานในเวอร์ชันที่ติดตั้งจริง

แฟล็ก --safe คืออะไร?

ใช้คำสั่ง open -a Lamoon --args --safe เพื่อเปิด Lamoon ในโหมดปลอดภัย โดยใช้ค่าการแสดงผลเริ่มต้นที่ปลอดภัยแทนค่าที่บันทึกไว้ เหมาะสำหรับแก้ปัญหาจากการตั้งค่าหรือการปรับหน้าจอ ไม่ใช่เครื่องมือลบข้อมูลทั่วไป

ใช้ Lamoon ระหว่างแชร์หน้าจอได้หรือไม่?

Film (เลเยอร์ทับภาพ) อาจปรากฏในภาพหน้าจอ วิดีโอ หรือการแชร์หน้าจอบางรูปแบบ ขึ้นอยู่กับวิธีจับภาพ Capture Mode พักการหรี่จอ 5 วินาทีสำหรับภาพนิ่ง ไม่ใช่โหมดแชร์หน้าจอต่อเนื่อง ควรทดสอบก่อนประชุม หรือทดลอง Display Gamma หากจอรองรับ

Lamoon ทำงานร่วมกับ Stage Manager ได้หรือไม่?

Lamoon สามารถทำงานร่วมกับ Stage Manager ได้ แต่ Film ใช้หน้าต่าง overlay ซึ่งอาจมีพฤติกรรมต่างกันเมื่อสลับหน้าต่างหรือ Spaces ของ macOS ส่วน Display Gamma ปรับผ่านตารางถ่ายโอนค่าของจอ แต่จอบางรุ่นอาจไม่รองรับ ควรทดสอบทั้งสองโหมดบน Mac ของคุณ และไม่รับประกันความเข้ากันได้กับ Stage Manager ในทุกการตั้งค่า

Lamoon ต่างจาก Dark Mode ของ macOS อย่างไร?

Dark Mode ของ macOS เปลี่ยนรูปลักษณ์ของส่วนติดต่อและแอปที่รองรับ ส่วน Lamoon เน้นการหรี่จอด้วยซอฟต์แวร์และการควบคุมโทนสี รวมถึงการหรี่ได้สูงสุด 80% โทนสี 6 แบบ และ White Point ใน Display Gamma ผลลัพธ์ขึ้นอยู่กับจอและโหมด

Lamoon ต้องมีบัญชีผู้ใช้หรือมีโฆษณาหรือไม่?

เวอร์ชันที่อธิบายบนเว็บไซต์นี้ไม่ต้องสร้างบัญชีหรือลงชื่อเข้าใช้ และซอร์สโค้ดที่ตรวจสำหรับเว็บไซต์นี้ไม่มี SDK โฆษณาหรือวิเคราะห์ข้อมูล ทั้งนี้เวอร์ชันในอนาคตอาจเปลี่ยนแปลงได้

เกี่ยวกับ · Lamoon

Lamoon เป็นแอป macOS บนแถบเมนูที่ช่วยให้ควบคุมการหรี่จอและโทนสีได้ละเอียดขึ้น โดยเฉพาะในห้องแสงน้อย ช่วงค่ำ หรือระหว่างทำงานที่ต้องใช้สมาธิ

การหรี่ด้วยซอฟต์แวร์ไม่ได้ควบคุมไฟ Backlight จริงของจอ ผลลัพธ์อาจแตกต่างตาม Mac จอ macOS และโหมดที่เลือก โหมด Display Gamma อาจมีข้อจำกัดกับ HDR หรือเครื่องมือปรับการแสดงผลอื่น Lamoon ไม่กล่าวอ้างผลทางการแพทย์ มีป้ายคำแนะนำและคำอธิบายในแอปเพื่อช่วยอธิบายตัวควบคุมแต่ละรายการขณะใช้งาน
