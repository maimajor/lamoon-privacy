Lamoon 隐私政策

本政策说明 macOS 版 Lamoon 应用及其目前有文档记录的行为，不替代 GitHub 或你访问的其他网站各自的隐私政策。

最后更新：2026年10月24日

保存在 Mac 本机的信息

Lamoon 将屏幕设置、预设、语言、快捷键和定时计划等应用偏好保存在 macOS 沙盒容器中的 UserDefaults。这些设置用于提供你选择的功能。

大致位置与日出日落定时

只有启用可选的日出日落定时后，Lamoon 才可能通过 macOS 定位服务请求大致位置，以估算当地日出和日落时间。坐标会四舍五入到小数点后两位（具体精度因位置而异，约为公里级），并保存在本机；不会发送给开发者或第三方。如果拒绝权限或无法获取位置，可以改用手动定时。

数据收集与共享

当前项目文档和已检查的源代码表明，Lamoon 不会收集或传输个人数据。检查的源代码中未发现分析、广告、遥测或崩溃报告 SDK，也未发现网络上传代码。隐私清单未声明收集的数据类型或跟踪。本说明针对已检查的源代码快照。

保存与删除

应用偏好设置和经过四舍五入的位置会保留在应用的本地沙盒容器中。卸载应用不一定会删除该容器。若要在卸载后删除已保存设置，可在 Finder 中删除 ~/Library/Containers/com.maimajor.lamoon/。这也会删除 Lamoon 保存的偏好设置。

外部链接与网站托管

本政策适用于 macOS 版 Lamoon 应用。打开 GitHub、邮件链接或其他网站时，相应服务可能按其自身条款和隐私政策处理信息。本网站托管于 GitHub Pages，因此托管基础设施可能依照 GitHub 的政策处理基本请求信息。

政策变更

如果 Lamoon 的功能或数据处理方式发生变化，本政策可能会更新。
