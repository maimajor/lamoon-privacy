Lamoon 개인정보 처리방침

이 방침은 macOS용 Lamoon 앱과 현재 문서화된 동작을 설명합니다. GitHub 또는 방문하는 다른 웹사이트의 개인정보 처리방침을 대신하지 않습니다.

최종 업데이트: 2026년 10월 24일

Mac에 저장되는 정보

Lamoon은 화면 설정, 프리셋, 언어, 단축키, 일정 등 앱 환경설정을 macOS 샌드박스 컨테이너의 UserDefaults에 로컬 저장합니다. 이 설정은 사용자가 선택한 기능을 제공하는 데 사용됩니다.

대략적인 위치와 일출·일몰 일정

선택형 일출·일몰 일정을 켜면 현지 일출과 일몰을 추정하기 위해 macOS 위치 서비스를 통해 대략적인 위치를 요청할 수 있습니다. 좌표는 소수점 둘째 자리까지 반올림(위치에 따라 대략 1km 규모)되어 Mac에 로컬 저장되며 개발자나 제3자에게 전송되지 않습니다. 권한을 거부하거나 위치를 사용할 수 없으면 수동 일정을 이용할 수 있습니다.

데이터 수집 및 공유

현재 프로젝트 문서와 검토한 소스에 따르면 Lamoon은 개인 데이터를 수집하거나 전송하지 않습니다. 검토한 소스에서 분석, 광고, 원격 측정, 충돌 보고 SDK 또는 네트워크 업로드 코드는 발견되지 않았습니다. 개인정보 매니페스트에도 수집 데이터 유형이나 추적이 선언되어 있지 않습니다. 이 설명은 검토한 소스 스냅샷을 기준으로 합니다.

보관 및 삭제

설정과 반올림된 위치 정보는 앱의 로컬 샌드박스 컨테이너에 남습니다. 앱을 제거해도 컨테이너가 반드시 삭제되는 것은 아닙니다. 제거 후 저장된 설정을 삭제하려면 Finder에서 ~/Library/Containers/com.maimajor.lamoon/ 폴더를 삭제할 수 있습니다. 이 작업은 Lamoon의 저장 설정도 삭제합니다.

외부 링크 및 웹사이트 호스팅

이 방침은 macOS용 Lamoon 앱에 적용됩니다. GitHub, 이메일 링크 또는 다른 웹사이트를 열면 해당 서비스는 자체 약관과 개인정보 정책에 따라 정보를 처리할 수 있습니다. 이 사이트는 GitHub Pages에서 호스팅되므로 호스팅 인프라가 GitHub 정책에 따라 기본 요청 정보를 처리할 수 있습니다.

방침 변경

Lamoon의 기능이나 데이터 처리 방식이 바뀌면 이 방침을 업데이트할 수 있습니다.
