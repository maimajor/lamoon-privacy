Privacy Policy — Lamoon

This policy describes the Lamoon macOS app and its currently documented behavior. It does not replace the privacy policies of GitHub or other websites you may visit.

Last updated: 24 October 2026

Information stored on your Mac

Lamoon stores app preferences—such as display settings, presets, language, hotkeys and schedule—in UserDefaults inside its macOS sandbox container. These settings support the features you choose.

Approximate location and Solar Scheduling

If you enable Solar Scheduling, Lamoon may request approximate location through macOS Location Services to estimate local sunrise and sunset. Coordinates are rounded to two decimal places (roughly kilometer-scale, depending on location) and stored locally for this feature. The app does not send these coordinates to the developer or other third parties. If permission is denied or location is unavailable, you can use manual scheduling.

Data collection and sharing

The current project documentation and source code indicate that Lamoon does not collect or transmit personal data. The current source code available on GitHub contains no analytics, advertising, telemetry, or crash-reporting SDKs, and no code that uploads data over the network. The privacy manifest declares no collected data types and no tracking. This statement describes the current version of the app; this policy should be reviewed if a future version changes how it handles data.

Retention and deletion

Preferences and rounded Solar Scheduling coordinates remain in the app’s local sandbox container. Uninstalling the app does not necessarily remove this container. To remove stored settings after uninstalling, you can delete ~/Library/Containers/com.maimajor.lamoon/ in Finder. This also removes Lamoon’s saved preferences.

External links and website hosting

This policy covers the Lamoon macOS app. When you follow a link to GitHub, open an email link or visit another website, that service may process information under its own terms and privacy policy. This site is hosted on GitHub Pages, whose hosting infrastructure may process basic request information under GitHub’s policies.

Changes to this policy

This policy may be updated when Lamoon’s features or data handling change.
