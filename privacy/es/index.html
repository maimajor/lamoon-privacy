Política de privacidad — Lamoon

Esta política describe la app Lamoon para macOS y su comportamiento documentado actual. No sustituye las políticas de privacidad de GitHub ni las de otros sitios que visites.

Última actualización: 24 de octubre de 2026

Información guardada en tu Mac

Lamoon guarda las preferencias de la app —como los ajustes de pantalla, preajustes, idioma, atajos y programación— en UserDefaults, dentro del contenedor aislado de macOS. Se utilizan para ofrecer las funciones que eliges.

Ubicación aproximada y horario solar

Si activas el horario solar opcional, Lamoon puede solicitar una ubicación aproximada mediante los servicios de localización de macOS para estimar el amanecer y el atardecer locales. Las coordenadas se redondean a dos decimales (aproximadamente a escala de un kilómetro, según el lugar) y se guardan localmente. No se envían al desarrollador ni a terceros. Si deniegas el permiso o no hay ubicación disponible, puedes usar un horario manual.

Recopilación y uso compartido de datos

La documentación actual y el código fuente revisado indican que Lamoon no recopila ni transmite datos personales. En el código revisado no se encontraron SDK de analítica, publicidad, telemetría o informes de fallos, ni código para subir datos por red. El manifiesto de privacidad no declara tipos de datos recopilados ni seguimiento. Esta afirmación se refiere a la instantánea revisada del código fuente.

Conservación y eliminación

Las preferencias y la ubicación redondeada permanecen en el contenedor local de la app. Desinstalarla no elimina necesariamente ese contenedor. Para borrar los ajustes guardados después de desinstalar, puedes eliminar en Finder ~/Library/Containers/com.maimajor.lamoon/. Esto también elimina las preferencias guardadas de Lamoon.

Enlaces externos y alojamiento del sitio

Esta política se refiere a la app Lamoon para macOS. Al abrir GitHub, un enlace de correo u otro sitio, ese servicio puede procesar información conforme a sus propias condiciones y política de privacidad. El sitio está alojado en GitHub Pages, cuya infraestructura puede procesar información básica de solicitudes según las políticas de GitHub.

Cambios en esta política

Esta política puede actualizarse cuando cambien las funciones o el tratamiento de datos de Lamoon.
