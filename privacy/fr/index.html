Politique de confidentialité — Lamoon

Cette politique décrit l’app Lamoon pour macOS et son comportement actuellement documenté. Elle ne remplace pas les politiques de confidentialité de GitHub ni celles des autres sites que vous consultez.

Dernière mise à jour : 24 octobre 2026

Informations enregistrées sur votre Mac

Lamoon stocke les préférences de l’app — réglages d’écran, préréglages, langue, raccourcis et programmation — dans UserDefaults, au sein du conteneur sandbox de macOS. Ces préférences servent aux fonctions que vous choisissez.

Localisation approximative et programmation selon le soleil

Si vous activez la programmation facultative selon le lever et le coucher du soleil, Lamoon peut demander une localisation approximative via les services de localisation de macOS. Les coordonnées sont arrondies à deux décimales (environ un kilomètre selon le lieu) et conservées localement. Elles ne sont envoyées ni au développeur ni à des tiers. Si vous refusez l’autorisation ou si la localisation est indisponible, vous pouvez utiliser un horaire manuel.

Collecte et partage des données

La documentation actuelle et le code source examiné indiquent que Lamoon ne collecte ni ne transmet de données personnelles. Aucun SDK d’analyse, de publicité, de télémétrie ou de rapport de plantage, ni code d’envoi réseau, n’a été trouvé dans le code examiné. Le manifeste de confidentialité ne déclare aucune catégorie de données collectées ni aucun suivi. Cette déclaration se rapporte à la version du code examinée.

Conservation et suppression

Les préférences et la localisation arrondie restent dans le conteneur sandbox local de l’app. La désinstallation ne supprime pas forcément ce conteneur. Pour supprimer les réglages après la désinstallation, vous pouvez supprimer dans Finder ~/Library/Containers/com.maimajor.lamoon/. Cela efface également les préférences enregistrées de Lamoon.

Liens externes et hébergement du site

Cette politique concerne l’app Lamoon pour macOS. Lorsque vous ouvrez GitHub, un lien e-mail ou un autre site, ce service peut traiter des informations selon ses propres conditions et sa politique de confidentialité. Le site est hébergé sur GitHub Pages ; son infrastructure peut traiter des informations de requête de base selon les politiques de GitHub.

Modifications de cette politique

Cette politique peut être mise à jour si les fonctions ou le traitement des données de Lamoon changent.
