นโยบายความเป็นส่วนตัว — Lamoon

นโยบายนี้อธิบายแอป Lamoon สำหรับ macOS และพฤติกรรมตามเอกสารของโปรเจกต์ในปัจจุบัน ไม่ได้แทนนโยบายของ GitHub หรือเว็บไซต์อื่นที่คุณเข้าเยี่ยมชม

ปรับปรุงล่าสุด: 24 ตุลาคม 2026

ข้อมูลที่เก็บไว้ใน Mac

Lamoon เก็บค่าตั้งค่า เช่น การปรับหน้าจอ พรีเซ็ต ภาษา ปุ่มลัด และตารางเวลาไว้ใน UserDefaults ภายใน sandbox container ของ macOS เพื่อให้ฟีเจอร์ที่คุณเลือกทำงานได้

ตำแหน่งโดยประมาณและการตั้งเวลาตามพระอาทิตย์

หากเปิดการตั้งเวลาตามพระอาทิตย์ Lamoon อาจขอตำแหน่งโดยประมาณผ่าน macOS Location Services เพื่อประมาณเวลาพระอาทิตย์ขึ้นและตก พิกัดจะปัดเศษเป็นทศนิยม 2 ตำแหน่ง (ความละเอียดประมาณระดับกิโลเมตรและขึ้นอยู่กับตำแหน่ง) และเก็บไว้ในเครื่อง แอปไม่ส่งพิกัดให้ผู้พัฒนาหรือบุคคลที่สาม หากปฏิเสธสิทธิ์หรือระบุตำแหน่งไม่ได้ ยังใช้การตั้งเวลาแบบกำหนดเองได้

การเก็บและแบ่งปันข้อมูล

เอกสารโปรเจกต์และซอร์สที่ตรวจสอบระบุว่า Lamoon ไม่เก็บหรือส่งข้อมูลส่วนบุคคล ซอร์สที่ตรวจสอบไม่พบ SDK วิเคราะห์ข้อมูล โฆษณา telemetry หรือรายงานแอปขัดข้อง และไม่พบโค้ดอัปโหลดข้อมูลผ่านเครือข่าย Privacy Manifest ระบุว่าไม่มีประเภทข้อมูลที่เก็บรวบรวมหรือการติดตาม ข้อความนี้อ้างอิงซอร์ส snapshot ที่ตรวจสอบ การเปลี่ยนแปลงในอนาคตควรได้รับการตรวจอีกครั้ง

ระยะเวลาเก็บและการลบ

ค่าตั้งค่าและพิกัดที่ปัดเศษแล้วจะอยู่ใน sandbox container ของแอป การถอนการติดตั้งไม่ได้รับประกันว่า container จะถูกลบ หากต้องการลบข้อมูลหลังถอนการติดตั้ง คุณสามารถลบ ~/Library/Containers/com.maimajor.lamoon/ ผ่าน Finder ได้ การทำเช่นนี้จะลบค่าตั้งค่าที่บันทึกไว้ด้วย

ลิงก์ภายนอกและการโฮสต์เว็บไซต์

นโยบายนี้ครอบคลุมเฉพาะแอป Lamoon สำหรับ macOS เมื่อเปิด GitHub ลิงก์อีเมล หรือเว็บไซต์อื่น บริการนั้นอาจจัดการข้อมูลตามเงื่อนไขและนโยบายของตน เว็บไซต์นี้โฮสต์บน GitHub Pages ซึ่งระบบโฮสต์อาจประมวลผลข้อมูลคำขอพื้นฐานตามนโยบายของ GitHub
