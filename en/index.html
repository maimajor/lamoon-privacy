A MORE FLEXIBLE MAC DISPLAY

Still too bright even at the lowest brightness?

When macOS brightness is already at its lowest and the screen still feels too bright, Lamoon adds software dimming and display-tone controls in one menu-bar panel. It does not control the display’s physical backlight.

Two display-adjustment methods

Lamoon changes how content is displayed; it does not directly control the panel’s physical backlight.

◧

Film (overlay)

Places a dimming layer over the displayed image. It is the recommended fallback when gamma adjustments have no effect. Like other overlay-based tools, the layer may appear in screenshots or recordings.

◐

Display Gamma

Adjusts the display’s gamma table and enables White Point. Some HDR/XDR displays and other display-adjustment tools may limit or conflict with this method.

Lamoon glossary: key display terms

Short definitions for the display controls and settings mentioned throughout this page.

Software dimming

Reducing the apparent brightness of displayed content with an overlay or a display gamma-table adjustment, rather than directly changing the panel’s physical backlight.

Film (overlay)

A translucent layer placed over display content. It is Lamoon’s overlay-based method and may appear in screenshots or recordings.

Display Gamma

A mode that adjusts a display’s gamma or transfer table. It enables White Point control, but some displays and HDR/XDR configurations may not respond as expected.

White Point

A control for reducing the intensity of the brightest whites separately from the overall dimming effect. In Lamoon, it is available only in Display Gamma mode.

Warmth / “Blue light” slider

A control that shifts displayed colors toward warmer tones. It does not measure how much blue light the screen emits or verify how much is blocked.

Color tone

A selectable display filter: True (untinted), Warm, Amber, Deep, Red or Green.

Preset

A saved combination of dimming, warmth, White Point and color-tone settings, designed as a quick starting point.

Solar Scheduling

An optional schedule based on local sunrise and sunset times. Approximate location is requested only when you enable it through macOS Location Services; coordinates are rounded to two decimal places and stored locally on your Mac.

Night Boost

When automatic night mode is active, Night Boost can raise dimming to 50% and warmth to 35% once per night. It restores only the values it raised, and only if you have not changed them since.

Capture Mode

A five-second pause of dimming for a still screenshot. It is not a continuous screen-sharing or recording mode.

Hot-plug display detection

Responding to macOS display-configuration changes when a monitor is connected or disconnected while Lamoon is running.

Frequently asked questions

Can Lamoon make my Mac screen darker than the built-in minimum?

Yes. Lamoon adds software dimming with a control up to 80%. The visible result depends on your display and the selected mode.

Does Lamoon change the display’s physical backlight?

No. Depending on the selected mode, Lamoon uses an overlay or adjusts the display’s gamma table. It does not directly lower the physical backlight.

What is the difference between Film (overlay) and Display Gamma?

They are two software display methods. Compatibility and appearance can vary by display and mode. White Point (up to 80%) is available only in Display Gamma mode.

Does the Blue light slider measure how much blue light the screen emits?

No. It adjusts the image toward a warmer color tone; it is not a measurement of emitted blue light. The slider displays 0–100%, while the internal tint blend is capped at 80%.

What do the six presets change?

They provide quick starting points: Normal (0%), Work (20%), Coding (35%), Reading (45%), Movie (65%) and Bedtime (80%) dimming. Presets can also apply their saved warmth, white-point and tone settings.

Does Solar Scheduling need my location?

Location is needed only for optional sunrise/sunset scheduling. Lamoon requests approximate location through macOS Location Services, rounds coordinates to two decimal places (roughly kilometer-scale, depending on location), and stores them locally on your Mac. Manual scheduling works without location access.

What does Night Boost do?

When automatic night mode is active, Night Boost can raise dimming to 50% and warmth to 35% once per night. It restores only the values it raised, and only if you have not changed those values in the meantime.

What does Capture Mode do?

Capture Mode pauses dimming for five seconds so you can capture a still image. It is not a continuous screen-sharing mode.

Does Lamoon dim the lock screen?

Lock-screen dimming is enabled by default and can be turned off. While active, dimming on the lock screen is limited to 45%.

Does Lamoon collect or send personal data?

Lamoon stores preferences and approximate Solar Scheduling coordinates locally on your Mac. The source code checked for this site contains no analytics, advertising, telemetry, crash-reporting SDKs, or network-upload code. Future versions may differ. The website and GitHub require an internet connection to view or download project files.

Which macOS versions are supported, and are there limitations?

Lamoon targets macOS 13 and later. Display Gamma may have compatibility limitations with HDR displays or other tools that modify display output; results vary by Mac, display and mode.

How can I reset the display quickly?

Use Control–Command–0 to reset the display adjustments. This shortcut works without enabling custom hotkeys; other custom hotkeys are off by default and can be enabled in settings.

Can I set my own schedule?

Yes. Choose manual start and end times, or use sunrise/sunset scheduling. Manual scheduling does not require location access; approximate location is requested only when solar scheduling is enabled.

Can I pause dimming temporarily?

Yes. Pause dimming to restore normal display brightness, then resume when you want the extra dimming again.

What happens when I select the True tone?

True pauses warmth tinting and disables the Warmth slider while preserving its current value. The saved slider value remains available when you select another tone.

How do I install Lamoon?

Open the project on GitHub and check Releases for a published build. If a downloadable app is available, follow the release notes; a standard Lamoon.app can be moved to Applications and launched from there.

Where is the Lamoon icon after launch?

Lamoon is designed to run from the macOS menu bar rather than as a regular Dock app. Look for its moon icon near the menu bar controls.

Does Lamoon need an internet connection?

The reviewed app source contains no network-upload code and Lamoon’s core display controls are local. The website or GitHub will still need internet access to browse or download project files.

Is Lamoon free, and is it on the Mac App Store?

Check the project’s GitHub page and published release notes for current availability and pricing. Do not assume a Mac App Store release unless the project announces one.

Does Lamoon support Intel and Apple Silicon Macs?

Check the architecture listed for the build you download. A universal build supports both Intel and Apple Silicon; macOS 13 or later is required.

Why does Display Gamma not make my screen darker?

Some displays do not respond as expected to gamma-table changes, and HDR/XDR or other display tools can affect compatibility. Try Film mode as a fallback.

Can I use Lamoon with Night Shift?

They may run together, but the combined color result can vary. If colors look unexpected, try adjusting one tool at a time or switch Lamoon to Film mode.

Can I use Lamoon with f.lux?

Multiple tools that adjust display output may conflict. If you use f.lux, try Film mode or test one display-adjustment tool at a time.

Does Lamoon work with external monitors?

Lamoon provides software display adjustments, but results vary with the monitor, connection, macOS, and selected mode. It does not directly set a monitor’s physical backlight.

Does Lamoon work with HDR or XDR displays?

Display Gamma may have limitations with HDR/XDR displays. Try Film mode if gamma adjustments do not work as expected.

Does dimming appear in screenshots or recordings?

The Film overlay can be captured in screenshots or recordings. Capture Mode pauses dimming for five seconds for a still capture; it is not intended for continuous screen sharing.

Can I schedule dimming without sharing my location?

Yes. Choose manual start and end times. Location access is only needed for optional sunrise/sunset scheduling.

Where are my settings stored, and can I remove them?

Settings are stored locally in Lamoon’s macOS app container. To remove saved preferences and local location data, quit Lamoon and remove its container folder from your user Library; doing so deletes stored app settings too.

What should I try if custom hotkeys do not work?

Custom hotkeys are off by default. Enable them in settings, then choose a different key combination if another app uses the same shortcut.

Does Lamoon affect Mac performance or battery life?

Resource use and battery impact can depend on the selected mode, connected displays, and what macOS is doing. We have not published controlled battery benchmarks, so we cannot promise negligible impact. You can compare Lamoon’s Energy Impact in Activity Monitor on your own Mac.

Does Lamoon run in the background?

Yes. Lamoon is a menu-bar utility and can keep applying your display settings while its control panel is closed. The panel does not need to stay open for the selected dimming effect to remain active.

Can I quit Lamoon completely?

Choose Quit from Lamoon’s menu or use the app’s Quit control. On termination, Lamoon attempts to restore display gamma tables it changed. If your display still looks unexpected, reopen Lamoon and use Control–Command–0 to reset the adjustments.

Does Lamoon start automatically with macOS?

Launch at login is optional and off by default. Enable it in Lamoon settings if you want the app to start when you sign in.

Does Lamoon dim all connected displays?

Lamoon is designed to apply display adjustments to the screens that macOS detects, including built-in and external displays. Film (overlay) can cover screens that macOS detects. Display Gamma can vary by display, and the app uses an overlay fallback when gamma adjustment cannot be applied. Results still depend on the hardware and macOS configuration.

What happens when I connect or disconnect an external display?

Lamoon responds to macOS display-configuration changes and refreshes its display overlays. It should adapt after macOS recognizes the monitor, although a brief delay can occur. If the result looks wrong, try Film mode or reopen Lamoon.

Does Lamoon work with mirrored displays?

Mirrored-display behavior depends on how macOS exposes the mirror arrangement and the selected mode. Lamoon handles displays that macOS detects, but we do not guarantee identical results for every mirror setup. If the output is unexpected, test Film mode and check each display configuration.

Does Lamoon work with Sidecar (iPad as a second display)?

If macOS exposes the Sidecar iPad as a display, Lamoon’s Film overlay can address displays that macOS detects. Display Gamma support and the visible result can vary. Sidecar-specific behavior has not been independently certified for every setup.

Does Lamoon support keyboard navigation?

The custom dimming sliders expose accessibility labels and values, can receive keyboard focus, and support arrow-key adjustment. For broader keyboard navigation, enable Full Keyboard Access in macOS System Settings. Exact navigation can vary by control and macOS version.

Is Lamoon accessible for screen-reader users?

Lamoon’s custom sliders have accessibility labels and adjustable actions. Not every workflow has been tested with every screen reader, so test the current build with VoiceOver before relying on a specific workflow. Film mode is visual and does not provide spoken (VoiceOver) output.

Can I use Lamoon without a mouse?

Some controls, including the custom dimming sliders, support keyboard focus and arrow-key adjustment. Enable Full Keyboard Access in macOS System Settings for broader navigation. Keyboard coverage can vary by control and macOS version, so verify the workflow in your installed release.

What is the --safe flag?

Run open -a Lamoon --args --safe to start Lamoon in safe mode. It uses safe default display settings instead of saved preferences, helping troubleshoot problems caused by saved settings or display adjustments. It is not a general-purpose data deletion tool.

Can I use Lamoon while screen sharing?

The Film overlay may appear in screenshots, recordings, or some screen-sharing paths; behavior depends on the capture method. Capture Mode pauses dimming for five seconds for a still capture and is not a continuous screen-sharing mode. Test before a meeting, or try Display Gamma if your display supports it.

Does Lamoon work with Stage Manager?

Lamoon can run alongside Stage Manager, but Film mode uses overlay windows and behavior can vary during macOS window and Space transitions. Display Gamma adjusts the display transfer table, but some displays may not support it. Test both modes on your Mac; compatibility with Stage Manager is not guaranteed on every setup.

How is Lamoon different from macOS Dark Mode?

macOS Dark Mode changes the appearance of supported interface elements and apps. Lamoon focuses on software dimming and display-tone controls, including up to 80% dimming, six color tones and White Point in Display Gamma mode. The effect depends on the display and selected mode.

Does Lamoon require an account or show ads?

Lamoon does not require an account or sign-in in the version described here. The source code checked for this site contains no advertising or analytics SDKs. Future versions may differ.

About · Lamoon

Lamoon is a macOS menu-bar app for people who want more control over screen dimming and display tone, especially in dim rooms, in the evening, or during focused work.

Software dimming does not control the display’s physical backlight. Display behavior can vary by Mac, display, macOS version and selected mode. Display Gamma may have limitations with HDR or other display-modifying tools. Lamoon makes no medical claims. Inline help badges and tooltips explain the app’s controls as you use them.
